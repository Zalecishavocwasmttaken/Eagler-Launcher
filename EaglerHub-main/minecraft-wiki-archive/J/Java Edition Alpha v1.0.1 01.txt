Alpha v1.0.1_01 is a version of Java Edition Alpha released on July 2, 2010, to fix a Linux mouse bug. This is the first Minecraft Alpha version to use an underscore in its name.


== Additions ==
Added redstone dust to monster room chests.


== Fixes ==
1 bug fixed

Fixed a Linux mouse bug.


== Trivia ==
This is currently the oldest archived version of Alpha.
