Copper, Collaborate & Compete or Copper, Collaboration & Compete is a minor update to Minecraft Education released on February 17, 2026, as Minecraft Education 1.21.132. It adds features from the The Copper Age and Mounts of Mayhem game drops.


== Additions ==

Added features from Bedrock Edition 1.21.93 to Bedrock Edition 1.21.132, The Copper Age and Mounts of Mayhem.
Added the "Lava Chicken" music disc from Bedrock Edition 1.21.93.
Added dedicated servers.


== Changes ==


=== General ===
Python Notebooks has been removed as a supported IDE.


== Further revisions ==
1.21.133 was released to enable chat logging for dedicated servers, update sign in security, improve Code Builder stability and fix bugs.
