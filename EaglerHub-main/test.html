How the encoding works

due to how my encoder works we have to make a simple url decoder to make the correct links for my site to work

01
Normalize the destinationThe proxy can resolve a domain to a final URL. For example, a domain may redirect to another hostname or add a path.
02
XOR every second characterCharacters at indexes 1, 3, 5, ... are XORed with 2. This matches the Ultraviolet XOR URL codec pattern.
03
URL-encode the resultThe transformed string is passed through encodeURIComponent(), producing values such as %2F and %3A.
04
Add the kwtw prefixThe encoded result becomes the path after https://s3.amazonaws.com/ilovemaths/kwtw/.
Important: the encoder reproduces the confirmed transformation, but a plain static HTML file cannot know a site's redirect/final URL without resolving it first. The examples showed that the proxy may encode the resolved destination rather than the original text.
