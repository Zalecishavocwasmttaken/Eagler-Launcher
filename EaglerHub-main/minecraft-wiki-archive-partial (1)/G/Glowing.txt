Glowing is a status effect that shows entity positions through blocks.

Effect
The glowing effect added to entities using /effect
The Glowing effect causes entities to glow with an outline that can be seen through blocks and entities. This outline is white by default, but can be set to display other colors if the entity is part of a team (the color being the color of the team). The outline displays around any holes in a mob's texture or model, though only when that part of the model can be seen all the way through. If multiple entities with glowing are near each other, the outlines merge to prevent overlapping/Z-Fighting.
This does not affect mob models as seen in the inventory, of either the player or ridden mobs.

Hitting a bell applies the effect to any illagers, ravagers, or witches within 32 blocks of the bell.

Immune mobs
Withers, ender dragons, dropped items, interactions, and display entities are immune to Glowing.
