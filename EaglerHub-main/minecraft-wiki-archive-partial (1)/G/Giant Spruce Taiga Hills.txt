This feature was present in earlier versions of Java Edition, but has since been removed.

The giant spruce taiga hills or redwood taiga hills mutated biome is a modified hills variant of the giant tree taiga that no longer generates since Caves & Cliffs: Part II, and has been removed in Java Edition.

Description
Old
The giant spruce taiga hills was a variant intended to be a more mountainous version of the giant spruce taiga, like all other hills biomes. However, both Java Edition and Bedrock Edition had generation issues.
In Java Edition, due to a likely error in the way terrain height is calculated, there was no difference in the terrain between giant spruce taiga and giant spruce taiga hills. Specifically, the game used internal values known as setBaseHeight and setHeightVariation when generating hills biomes, but these values were the same for both giant spruce taiga and giant spruce taiga hills, resulting in no actual difference between the two. This was the only hills biome in the game with this issue.
In Bedrock Edition, this biome generated as a much hillier version of the giant spruce taiga, even more mountainous than regular hills biomes. The hills often reached the generation limit, and the tall trees made this the biome with the second highest blocks (up to Y=158), after the shattered savanna plateau. However, this biome generated the same trees as the giant tree taiga hills (not giant spruce trees, but giant pine trees), making this biome hardly distinctable from the giant tree taiga hills.

Current
In Bedrock Edition, giant tree taiga hills in older worlds still received updates. When generated through single biome or behavior packs, they can also generate new blocks.
The appear almost identical to the regular old growth pine taiga. Cold animal variants spawn as well as the rare chestnut wolf variants. The snowfall height is increased to Y=200±8, covering only the highest mountain peaks in snow, unlike regular old growth spruce taigas, where the snowfall height is 160. Trail ruins do not generate.
With Vibrant Visuals, giant spruce taiga hills use a coolish humid volumetric fog setting, which slightly fades the distance in an orange tint. Giant spruce taiga hills have coolish color grading tints the environment with a colder blue color, and cold sunlight which appears slightly brighter at dusk and dawn.

Giant spruce taiga hills use the same mob spawning chances as old growth spruce taigas.
