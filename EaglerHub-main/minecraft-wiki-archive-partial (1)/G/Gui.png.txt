This page describes content that has been removed from Java Edition. 
This feature was present in earlier versions of Java Edition, but has since been removed.

gui.png in Bedrock Edition.
gui2.png in Bedrock Edition.
widgets.png in Java Edition 1.20.1, the last version to use this file.
gui.png and gui2.png are texture atlases for storing textures of widgets in Bedrock Edition.
widgets.png (previously known as gui.png) was a texture atlas for storing textures of widgets in Java Edition.

Format
gui.png is a fixed-width 256×256-pixel file containing textures of most widgets, including hotbar and selection,  and unused red, green, and gray circles, crosshair (used one in icons.png), and old notification symbols for Realms.
gui2.png is an unused[check the code] fixed-width 256×256-pixel file containing old textures of some widgets.
widgets.png was a fixed-width 256×256-pixel file containing textures of all widgets, including hotbar and selection, dual wield slots, menu buttons, and unused red, green and gray circles, crosshair (used one in icons.png), and old notification symbols for Realms.
