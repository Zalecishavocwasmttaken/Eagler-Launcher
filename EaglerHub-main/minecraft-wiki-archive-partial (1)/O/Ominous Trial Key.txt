An ominous trial key is a type of trial key that can only be obtained from ominous trial spawners. It is used to unlock an ominous vault and obtain its loot.

Usage
Using an ominous trial key on an ominous vault while the player is affected by the Trial Omen effect unlocks it, causing it to eject items and the ominous trial key to be consumed. Vaults can only be unlocked once per player, unless 128 different players subsequently open it, causing the first player on the list to be forgotten.
In Java Edition, due to the bug MC-268183, any ominous trial key with non-standard data (e.g. a renamed ominous trial key) can't be used to open the standard ominous vault.
