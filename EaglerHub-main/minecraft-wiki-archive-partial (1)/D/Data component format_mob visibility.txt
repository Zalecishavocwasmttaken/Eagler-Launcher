[NBT Compound / JSON Object] minecraft:mob_visibility: Represents the visibility percentage provided by an item with the appropriate minecraft:equippable component, modifying the range at which mobs are able to detect an entity.
[String][NBT List / JSON Array] targeting_entity_types: An entity ID, a list of namespaced entity IDs, or a hash-prefixed entity tag.
[Float] visibility: The multiplier for the wearer's detectability by the aforementioned mobs. Valid range is 0f to 10f. A value of 0f reduces the wearer's detectability by these mobs to 2 blocks.​[more information needed] A value of 10f increases the detection radius tenfold. The maximum total detection multiplier from all equipped items with this component is 10.
