[String] minecraft:painting/variant: One painting variant (an [String] ID) — The variant of the painting. If present on an item, the item's tooltip will display: the painting's name (in yellow), the artist's name (in gray), and the painting's width & height in blocks (in white). Not all paintings have an artist attributed to them. If a painting item is in the creative inventory screen and this component is not present, a gray line of text that says "Random variant" is added to the tooltip instead.
