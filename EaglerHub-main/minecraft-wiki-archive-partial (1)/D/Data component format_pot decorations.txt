[NBT List / JSON Array] minecraft:pot_decorations​[until: JE 26.3]: A list of the items (typically pottery sherds or bricks) applied on each face of this decorated pot. If the list is specified with less than 4 entries, the remaining ones default to "minecraft:brick". The first entry is the front face of the pot, and subsequent entries are the faces going clockwise around the pot. If this component is present on an item, the item's tooltip will list the translated names of each of the items in the same order.
[String]: The ID of an item. Can be either brick or a sherd.
[NBT Compound / JSON Object] minecraft:pot_decorations​[upcoming: JE 26.3]: A map for face to the item stacks (typically pottery sherds or bricks). The faces can be empty. When used on a decorated pot, it defines the items that will be dropped from its faces when broken. If an item has the minecraft:provides_pottery_pattern component, it defines the texture of the corresponding face.
