Discord is an American instant messaging platform. Mojang Studios runs many different chat groups (known as servers) on Discord to provide a space for fans to talk with each other, receive official information, and in some cases to communicate with staff.

Minecraft Discord server
The first channel of the Minecraft Discord server, with the server's default theme applied.
The official Minecraft Discord server can be joined at discord.gg/minecraft. It is primarily in English, but also has a German language section.

Minecraft Feedback Discord server
The first channel of the Minecraft Feedback Discord server
The Feedback server functions similar to the feedback site where users can submit feedback on various forum boards. It can be joined at discord.gg/minecraftfeedback.
The feedback server has channels for Biomes and Dimensions, Blocks Tools and Items, Commands, Community Live Events, Controls, Discord, Gameplay, Graphics, Launcher, Minecraft Legends, Mobs and Animals, NPCs and Villagers, Parity, Redstone, Sounds, Structures, Updates, User Interface and Website. There are also more channel categories for specific updates, edition-specific technical features, and the bedrock edition marketplace.
Reactions are disabled, but users can upvote posts using an upvote reaction automatically added by a bot. However, the bot regularly stops functioning for extended lengths of time, which prevents new posts from being upvoted.

Mojira Discord server
File:Discord Mojira.pngThe first channel of the Mojira Discord server
The Mojira server provides information from the Minecraft bug tracker and allows users to engage with the site's moderators and some Mojang staff members that are working with the bug tracker.
It is not run by Mojang officially, but rather by the volunteer bug tracker staff.

These descriptions were taken from the Mojira Discord server's #welcome channel.

Discord Moderators
​[more information needed]
Moderating and administrating this Discord server. They can be pinged when immediate action is required in any of the Discord channels.

Mojira Moderators
​[more information needed]
Moderating Mojira and thus have the ability to edit, update, resolve, move or link tickets. They can be pinged if immediate action is required on the bug tracker. Not all moderators have moderating powers on this Discord server though. DO NOT ping for Discord-related emergencies.

Mojira Helpers
​[more information needed]
Help with keeping day-to-day business on the bug tracker going, and thus have the ability to edit and update other people's tickets. They may also help with moderating this Discord server.

Mojang staff
​[more information needed]
Present on this server as well. Keep in mind that they are not necessarily directly involved with the development of the game or with fixing bugs.

Bots
​[more information needed]
Non-human users that can post automatically.

Alumni
​[more information needed]
Former bug tracker moderators or helpers.

History
The server was publicly launched on December 8, 2019.
