[NBT Compound / JSON Object] minecraft:entity_data: NBT applied to an entity when created from an item.
[String] id: The resource location of the entity. If the item is a spawn egg and this id is falling_block, command_block_minecart, or spawner_minecart, this component adds a red message to the item's tooltip (for operator players only) warning the player that using it may result in command execution. Define the generating entity by spawn egg. For other items, it must be equal to the id of the entity generated by the item; otherwise, the component is not effective.
[Undefined] <any field>: Optional. See Entity format for effective fields, excludes id, UUID and Passengers. Applies the NTB tag to the entity if it is valid and applicable. Other fields can be added, but they have no effect.
