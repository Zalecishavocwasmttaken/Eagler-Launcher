[String][NBT Compound / JSON Object] minecraft:provides_trim_material: One trim material (an [String] ID, or a new [NBT Compound / JSON Object] trim material definition). When present, this item provides the specified trim material when used in a trimming recipe.
A trim material see Template:Nbt inherit/trim material/template

Notes

 To be used in the built-in smithing recipes, the item must also be in the #trim_material tag.
