[NBT Compound / JSON Object] minecraft:brewing_fuel: If present, this item can be consumed for fuel by brewing stands.
[Float][String] uses: How many infusions will be fueled by destroying this item. Either a fixed number or the namespaced ID of a number provider, which is evaluated using the container_process loot context when a brewing stand uses this item as fuel. The resolved value is rounded to the nearest whole number. The fuel item is consumed regardless of whether the result is a positive number.
[Float][String] speed_multiplier: How quickly infusions should brew during the time provided by this fuel item. Either a fixed number or the namespaced ID of a number provider, which is evaluated using the container_process loot context when a brewing stand uses this item as fuel. If the resolved value is 0.0 or less, it is treated as 1.0. Each infusion that starts while this fuel is active will take ceil(400  ÷  mult) ticks, meaning higher values brew quicker and lower values brew slower. The provider is only evaluated once when the fuel is consumed, and the scaled brewing time is only calculated once when the infusion begins.
