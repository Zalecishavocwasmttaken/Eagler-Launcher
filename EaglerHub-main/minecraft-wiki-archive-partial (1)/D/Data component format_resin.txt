[NBT Compound / JSON Object] resin: The properties of this toxic resin.
[String] quality：A single character represents the clarity of the toxic resin. The character corresponding to each clarity is their first letter. If the string is longer than 1, only the first character takes effect.
[String] impurities：A single character represents the impurity of the toxic resin. The character corresponding to each impurity is their first letter. If the string is longer than 1, only the first character takes effect.
