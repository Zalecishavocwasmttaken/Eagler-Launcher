This page describes content that has been removed from Minecraft. 
This feature was present in earlier versions of Minecraft, but has since been removed.



This feature is exclusive to Bedrock Edition and Minecraft Education. 

Developer commands are generally only enabled in the development and testing environment of the game. In release versions, players cannot see and execute these commands.
However, these developer exclusive commands were accidentally left in the iOS release of Bedrock Edition 1.2.13. They were removed in Bedrock Edition 1.2.14.
