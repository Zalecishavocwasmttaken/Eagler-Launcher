[NBT Compound / JSON Object] minecraft:compostable:
[Float][String] layers: Required. The number of compost layers added when using this item on a non-full composter (level less than 7). Either a fixed number or the namespaced ID of a number provider, which is evaluated using the block_interact loot context when the item is used. The optional block entity and tool loot context parameters are not supplied. The resolved value is rounded to the nearest whole number, and negative values are treated as 0. The final compost level after the new layers are added is clamped to the range 0–7.
