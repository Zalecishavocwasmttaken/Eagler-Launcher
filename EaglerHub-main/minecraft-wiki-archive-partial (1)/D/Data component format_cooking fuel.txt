[NBT Compound / JSON Object] minecraft:cooking_fuel: If present, this item can be burned for smelting fuel.
[Float][String] burn_time: How many ticks of fuel will be provided by destroying this item. Either a fixed number or the namespaced ID of a number provider, which is evaluated using the container_process loot context when a furnace tries to use this item as fuel. The resolved value is rounded to the nearest whole number, and if the result is 0, the item is not used as fuel on this tick.
[Float][String] speed_multiplier: How quickly items should smelt during the burn time provided by this fuel item. Either a fixed number or the namespaced ID of a number provider, which is evaluated using the container_process loot context when a furnace uses this item as fuel. If the resolved value is 0.0 or less, it is treated as 1.0. Each ingredient that starts cooking while this fuel is burning will take ceil(cookingtime  ÷  mult) ticks to cook, where cookingtime is specified in the recipe, meaning higher values cook quicker and lower values cook slower. The provider is only evaluated once when the fuel is consumed, and the scaled cooking time is only calculated once when the ingredient starts cooking.
