Beta 26.40.30 (ChromeOS, Android) or Preview 26.40.30 (Windows, iOS, iPadOS, Xbox, PlayStation) is the fifth beta/Preview for Bedrock Edition 26.40, released on July 6, 2026, for iOS and iPadOS, and on July 7, 2026, for all remaining devices, which adds experimental straw beds and cushions, and fixes bugs.

Changes
Blocks
Brown mushroom and red mushroom

Can no longer be placed under the sky when it is dark.
Now generate on crimson nylium and warped nylium no matter the brightness.
Stairs

All vanilla stairs no longer have the block state minecraft:corner.
General
Graphical

Updated supported devices for Vibrant Visuals on Android.
Technical
Actor Components

Made schemas for the following components stricter when parsing and will fail to load an entity json that has invalid data in versions 1.26.40 and newer:
minecraft:cannot_be_attacked
minecraft:floats_in_liquid
minecraft:ignore_cannot_be_attacked
minecraft:wants_jockey
API

Released LootItem.conditions in @minecraft/server v2.4.0 from beta.
Blocks

N-way rotation on geometry components no longer requires the Upcoming Creator Features experiment.
minecraft:sixteen_way_rotation state on placement direction block trait no longer requires the Upcoming Creator Features experiment.
Jigsaw Block replacement will now log when an invalid final_state is encountered.
Added new biome decoration feature minecraft:multi_block_feature, which can be used exclusively to place blocks defined with the minecraft:multi_block trait.
Released the minecraft:instrument_sound component from beta.
Commands

Using self selection expansion when using commands for non-operator players is now allowed.
Crafting

minecraft:recipe_smithing_transform now accepts items tagged with minecraft:transform_materials in its addition field.
DDUI

Added ImageOptions.onClick and ImageOptions.tooltip, which allow for a callback on click of an image and a tooltip on images for use with CustomForm.image.
Entity components

should_bounce boolean field of the minecraft:projectile component is now an enum:
no: the projectile never bounces (default).
if_invulnerable: the projectile bounces only when the target is invulnerable to the damage source (e.g. creative mode, shield blocking).
if_no_damage_dealt: the projectile bounces whenever no damage was dealt, regardless of the reason (invulnerability, damage sensor, invulnerability frames).
Content authored against earlier format versions is automatically upgraded when loaded in 1.26.40 or later: true becomes if_invulnerable and false becomes no.
Graphical

Tightened the anti-x-ray trigger box to avoid false-positive cases when riding a mob.
The MERS textures for following baby mobs and rabbits are now visible:
Baby Humanoid Chainmail Armor
Baby Dolphin
Baby Fox
Baby Goat
Baby Hoglin
Baby Panda
Baby Warm Pig
Baby Zombified Piglin
Snifflet
JSON Schema

Updated generated Minecraft JSON Schema files to use a more granular schema layout instead of producing one self-contained schema file per registered type. This reduces duplicated schema content and makes the generated schemas easier to consume with external tools.
Added binary-protocol metadata to generated SharedTypes JSON Schemas, including ordinal index, control value type, underlying type, and serialization options. This gives tools more information about the binary layout of the objects described by the JSON Schemas.
Mobs

Tamed baby wolves' collars now have a proper MERS texture.
Experimental
These additions and changes are accessible by enabling the "Beta APIs", "Upcoming Creator Features", "Render Dragon Features for Creators", and "Drop 3 of 2026" experimental toggles.

Additions
Blocks
 Straw bed

A new type of bed which can be used to sleep through the night without changing the spawn point.
It can only be used once and will be destroyed after use.
Cannot be used in the Nether or the End. It is destroyed upon use.
Generates in abandoned camps.
4 straw beds are crafted with 3 hay bales.

Ingredients
Crafting recipe

Hay Bale

4

Non-mob entities
 Cushion

A new entity that players can interact with to sit on.
Has 16 color variants, crafted with its respective variant of wool slab.

Ingredients
Crafting recipe

Matching Wool Slab

Can be placed on any flat surface.
Always aligns horizontally to the grid, but vertically sit on top of the supporting surface.
Breaks if the supporting block is removed.
Cannot be moved.
Does not have collision and can overlap with other objects (except other cushions).
Changes
Blocks
  Poplar door

Added hinges to the item texture.
Removed 3 pixels from the top door texture.
Poplar leaves

Updated ambient sounds for poplar leaves.
Added custom sound events for poplar leaves. Previously, they used stone sounds.
Red shrub

Added custom sound events.
World generation
Abandoned camp

Trees placed in abandoned camps are now procedurally generated.
General
Graphical

Changed dappled forest fog settings to match other forest biomes.
UI

Exiting the Dressing Room no longer automatically saves the character after an unequipped color change.
Updated the network disconnection message to direct players to enable "Use Mobile Data" in general settings instead of profile settings.
Updated Nintendo Switch terminology for local wireless multiplayer.
Updated Marketplace badges to use semantic tag styling for bordered and spacious variants, with refreshed tag documentation and tests.
After entering the sidebar in the Dressing Room while spinning the character it will no longer continue to spin by itself.
Players with multiplayer restricted skins can now enter worlds with multiplayer disabled.
Updated Marketplace content cards with new pass and rating iconography, refreshed Minecoin visuals, and a notice badge treatment for surfaced states.
Updated old world conversion flows in the Storage settings tab.
Technical
API

Added getShapes method on PrimitiveShapesManager.
Added interface PrimitiveShapeQueryOptions for use with getShapes.
Added AllowListEntry to @minecraft/server-admin with optional name and xuid properties in beta.
Changed AllowList in @minecraft/server-admin all in beta.
Added entries: AllowListEntry[] property
Changed add() to accept either a Player or AllowListEntry and removed accepting string as parameter. Adds InvalidArgumentError to this function when AllowListEntry has both name and xuid properties set to undefined.
Changed remove() to accept either a Player or AllowListEntry and removed accepting string as parameter. Adds InvalidArgumentError to this function when AllowListEntry has both name and xuid properties set to undefined.
Changed contains() to accept either a Player or AllowListEntry and removed accepting string as parameter. Adds InvalidArgumentError to this function when AllowListEntry has both name and xuid properties set to undefined.
Added new beta enum CloneMode with values Copy, ForceCopy, and Move that specifies how blocks are cloned between regions.
Dimension

Added cloneBlocks method to beta that clones a region of blocks from one area of the dimension to another, with support for clone modes and an optional block filter.
Graphical

Added a system to dynamically scale per-point-light shadow resources.
Increased the maximum number of point lights.
SoundDurationInfo

The playback position now reflects calls to SoundInstance.seekTo.
While a sound is paused via SoundInstance.pause, the playback position no longer advances; SoundInstance.resume continues from where it was paused.
Sounds

Added the minecaft:sound block component:
It requires the Upcoming Creator Features experiment.
It can be used to assign a set of sounds to block and its permutations similar to sound field in blocks.json.
blocks.json overrides values of minecraft:sound component, including values in all permutations.
Fixes
48 issues fixed

MCPE-60799 – Block breaking sounds originate on the South-East corner of the block.
MCPE-182130 – When activating or deactivating a resource pack, the formatting in toast notifications extends to regular text.
MCPE-194395 – Desert flat world preset uses an inaccurate world thumbnail.
MCPE-217896 – Azalea outer layer is transparent on the inside.
MCPE-229796 – "Watch out, game is no longer paused!" notification doesn't appear in the Dressing Room or the Achievements, Profile, and Social screens.
MCPE-236783 – Sliding up and down in the Creative inventory sometimes lags or is unresponsive on touch devices.
MCPE-237101 – Enable Game Pause toggle can no longer be accessed from main menu.
MCPE-237493 – Ambient occlusion differs between custom blocks and Vanilla blocks.
MCPE-237830 – Split-screen: Additional players can no longer change settings.
MCPE-239753 – Writing in a book and quill and closing it doesn't allow you to interact with anything in pre-26.30 worlds.
MCPE-239951 – Suspicious sand/gravel produce different loot in the same seed.
From the 26.40 development versions

MCPE-239456 – Screen safe area doesn't work for social drawer in pause menu.
MCPE-239756 – Potion tipped arrows bounce off Iron Golems and Ravagers after dealing damage instead of breaking.
MCPE-239804 – World list can fail to load after deleting worlds through "Manage worlds" button.
MCPE-240020 – All colors of poplar leaves display black spots when opaque.
MCPE-240024 – /locate structure command can freeze or crash the game when searching for non generating structure
MCPE-240036 – "Cloud storage is full" banner incorrectly states storage is both full and almost full.
MCPE-240040 – Wool stairs and slabs cannot be crafted from wool blocks.
MCPE-240045 – Abandoned Camps do not generate in pale gardens or flower forests.
MCPE-240097 – Charcoal can no longer be placed in the Lab Table, preventing Heat Blocks from being made.
Other

Fixed wrong potion names in the loot tables for the abandoned camp.
Fixed the poplar sign texture to follow other sign assets.
Fixed the focus indicator on the "More options" button on the start screen so it no longer relies on color alone, but adds an underline when the button is focused.
Fixed a miscolored pixel in one of the sulfur spike textures.
Fixed a rendering issue with Vibrant Visuals where some items and text could be invisible on certain Android GPUs.
Fixed a crash that could occur when spawning more than one iron golem at a time.
Fixed a crash that could occur during world generation when placing structures containing double chests.
Fixed a crash that could occur when concrete powder converts into concrete.
Fixed a bug where button touch areas did not align with the buttons in windowed Android modes with a title bar, such as Samsung DeX and pop up view.
Fixed a soft-lock that prevented further join attempts after a party leader's Experience join was blocked by the party eligibility check.
Fixed the "How to Play" button being missing from the Settings menu in Minecraft Education.
Fixed the beacon screen displaying a duplicated header in the Pocket UI.
Fixed the skin info button not working on expanded skin pack page.
Fixed the /clone command cloning partial beds.
Fixed the /fill command from improperly placing blocks defined with the minecraft:multi_block trait.
Fixed custom blocks rendering a stray solid face that could bleed through textures when a model face was hidden by setting one of its UV size dimensions to zero.
Fixed texture bleeding on custom blocks using automatic block face UV assignment with undersized textures.
Fixed a bug where the on_kill event in the following behavior components was incorrectly mapped to the on_attack field, causing the event to never fire when an entity killed its target. The fix applies to entity definitions with format version 1.26.40 and above:
minecraft:behavior.melee_attack
minecraft:behavior.melee_box_attack
minecraft:behavior.delayed_attack
minecraft:behavior.stomp_attack
minecraft:behavior.use_kinetic_weapon
Fixed minecraft:hopper_minecart to fire EntityItemPickupAfterEvent and EntityItemPickupBeforeEvent for items above the cart.
Fixed Images in CustomForms not being centered in the form.
Fixed incorrect example json for Height Difference Filter documentation.
Fixed a performance issue when in the Nether.
Fixed a bug where point light shadows would flicker during dynamic scaling.
Trivia
This Preview and other previews that were released after this (until Preview 26.50.25) do not have a release on https://github.com/Mojang/bedrock-samples, as the person formerly responsible for managing Bedrock samples, Mike Ammerlaan, left Mojang Studios on July 1st, 2026.
Starting from August 11, 2026, Bryce Bortree now releases the Bedrock samples.
