Bedrock Editor v1.3.4 (released as v26.20) is a minor release for the Bedrock Editor released in Preview on April 8, 2026, and in retail on May 5, 2026.

Contents

1 Fixes
2 References
3 Navigation

Fixes
Fixed an issue where Flatten Up was sampling too far into the ground.
Fixed an error that occurred when running the /reload command from tool mode chat shortcut.
Fixed Jigsaw Collection names allowing case-variant duplicates which caused file conflicts and potential data loss on case-insensitive file systems.
