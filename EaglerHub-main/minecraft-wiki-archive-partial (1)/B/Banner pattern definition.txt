A banner pattern is a shape that can be added to a banner.

JSON Format
Banner patterns are defined using the following format:

[NBT Compound / JSON Object] The root object.
[String] asset_id: The resource location for the texture asset.
[String] translation_key: The translation key for displaying the banner tooltip.
