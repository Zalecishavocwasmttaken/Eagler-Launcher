A blob is a feature consisting of basalt or blackstone blocks, which replaces netherrack blocks during world generation. They exclusively generate in basalt deltas and often overlap with other blobs.

 Blobs generate using either uniform distribution, or triangle distribution. Uniform distribution have all ores spread in same frequency at any height, while triangle generates more frequently in center height.

An example

{
  "type": "minecraft:netherrack_replace_blobs",
  "config": {
    "radius": {
      "type": "minecraft:uniform",
      "value": {
        "max_inclusive": 7,
        "min_inclusive": 3
      }
    },
    "state": {
      "Name": "minecraft:basalt",
      "Properties": {
        "axis": "y"
      }
    },
    "target": {
      "Name": "minecraft:netherrack"
    }
  }
}
