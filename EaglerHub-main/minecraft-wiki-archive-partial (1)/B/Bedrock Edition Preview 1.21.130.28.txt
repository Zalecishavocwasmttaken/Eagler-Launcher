Beta 1.21.130.28 (ChromeOS, Android) or Preview 1.21.130.28 (Windows, iOS, iPadOS, Xbox, PlayStation) is the sixth and final beta and seventh and final Preview version for Bedrock Edition 1.21.130, released on November 18, 2025, which fixes bugs. This is the last Preview/beta version to use the old version formatting.

Changes
Mobs
 Zombie Horse

No longer spawns on Peaceful difficulty.
Fixes
18 issues fixed
From released versions before 1.21.130

MCPE-176018 – Wolf's model has an offset to the left against their shadow
MCPE-179496 – Memory leak when the "Improved Input Response" option is enabled
MCPE-190684 – Player is unable to place additional pink petals, wildflowers or leaf litter by targeting a neighboring block
MCPE-228176 – Restarting the game after signing out signs the user back in when signed in before
MCPE-229154 – Vibrant Visuals setting is not available on Android devices using newer Adreno 722 GPUs
From the 1.21.130 development versions

MCPE-229439 – Spear Jabbing animation is tilted, compared to Java.
MCPE-229469 – Zombies spawning on Zombie Horse cannot spawn with Copper Armor
MCPE-230179 – Camel Husk Jockeys do not spawn naturally
MCPE-230208 – Video settings does not use the brand new Ore UI design, despite the changelog saying so
MCPE-230249 – Camel Husk sinks when ridden in the ocean
MCPE-230284 – Parched and Husk Mobs can 100% Immediately Ride Camel Husk (Java Edition Inconsistency)
MCPE-230871 – Neither Netherite Horse Armor nor Netherite Nautilus Armor provide knockback resistance
MCPE-231070 – (Java Parity) Husks do not drop rabbit feet when killed while riding a camel husk
MCPE-231364 – Wooded Badlands, Old Growth Spruce Taiga, and Snowy Taiga no longer generate with trees
MCPE-231485 – Game crashes on launch when the "Improved Input Response" option is enabled
MCPE-231518 – Repeated activation of LT and RT trigger buttons on Xbox
Other

Fixed an issue where IME Candidates would appear in the wrong monitor or misplaced in relation to text field.
Fixed blocks with the tick component not ticking when placed via a Jigsaw structure.
