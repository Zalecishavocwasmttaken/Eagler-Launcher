Bedrock Editor v0.4.1 is a minor alpha release for the Bedrock Editor released on July 12, 2023, which fixes some bugs and introduces the ability to see selection volumes and gizmos through blocks.

Contents

1 Additions
2 Fixes
3 References
4 Navigation

Additions
Tools

Selection volumes and gizmos can now be seen through blocks.
Fixes
Fixed a bug where Tool mode UI failed to refresh upon executing the /reload command (issue #1065550).
Number input fields will now adjust valid number values to the closest limit if they fall outside of the defined range.
Fixed an issue where UI text was exceeding the boundaries of panes and containers, resulting in improper alignment and visual inconsistencies.
