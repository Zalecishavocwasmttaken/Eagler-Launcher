26.41 (Nintendo Switch) or 26.42 (Windows) is a hotfix to Bedrock Edition released on August 7, 2026, for Windows and Nintendo Switch only, which disables cloud storage and fixes bugs.

Contents

1 Changes

1.1 General

2 Fixes
3 References
4 Navigation

Changes
General
Temporarily disabled cloud storage on Windows to address some issues discovered. (MCPE-241385)
Fixes
Fixed several crashes that could occur during gameplay.
Fixed missing assets when loading into a world if the network connection changed during start-up.
