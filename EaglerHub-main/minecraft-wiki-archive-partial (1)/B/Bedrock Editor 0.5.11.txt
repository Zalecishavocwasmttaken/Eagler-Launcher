Bedrock Editor v0.5.11 is a minor alpha release for the Bedrock Editor released on April 3, 2024, which adds the Block Hotbar and Time-of-Day Settings Panel, and makes some changes.

Additions
Block Hotbar
Block Picker
Block Hotbar

At the top of the Editor there is now a Block Hotbar to easily swap between the blocks player's tools use.
Click once or hit the corresponding key shortcut to select an element from the hotbar.
Click again to open the block picker to customize.
Editor extensions can leverage the hotbar using uiSession.extensionContext.blockPalette.getSelectedBlockType().
Time-of-Day Settings Panel

Accessible from World Options => Time of Day Settings.
Use Daylight Cycle to toggle between time being active/inactive.
Use the Presets dropdown to snap to a time, or use None and the slider to pick a moment-in-time.
Time Preset
Changes
New Line Tool
Updated Line Tool with new functionality and widget support.
Added ⎈ Control + A to select all widgets in a line.
Added ⎈ Control + D to deselect all widgets in a line.
Added continuous ⎈ Control + D to continually remove the last segment from the line list until it's empty.
Added ⇧ Shift + ⎈ Control + D to completely clear all selected widget and lines.
Added ⎈ Control + F to fill.
Added ⎈ Control + ⇧ Shift + F to fill and leave the line intact.
Added ⌦ Delete to fill the line with air.
Added ⇧ Shift + ⌦ Delete to fill and leave the line intact.
Added Keyboard movement (↑ Up, ↓ Down, ← Left, → Right, ⇞ Page Up, and ⇟ Page Down) to manually nudge selected end points.
Updated "Pause Actors" to "Pause Entities".
Updated block atlas file using different rendering technique.
