Bedrock Editor v0.8.3 is a minor beta release for the Bedrock Editor released on December 12, 2024.

Contents

1 Additions
2 Changes
3 Fixes
4 References
5 Navigation

Additions
Added data-driven rendering to editor block images:
Added block name aliasing for signs.
Added support for namespace block names for block:// protocol.
Changes
Updated player model to be fully hidden while in tool mode.
Fixes
Fixed an issue with thumbnail images to be centered in hotbar, block picker, and lists.
