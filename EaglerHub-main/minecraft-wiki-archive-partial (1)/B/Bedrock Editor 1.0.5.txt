Bedrock Editor v1.0.5 is a minor release for the Bedrock Editor released on July 22, 2025.

Contents

1 Changes
2 Fixes
3 References
4 Navigation

Changes
Updated Editor Structures to now be exported under the /structures folder in the world's directory when an Editor world is exported.
Updated tooltip API property of IToggleGroupPropertyItemEntry to take BasicTooltipContent.
Fixes
Fixed a bug where the selection highlight used the wrong color after changing the theme.
Fixed a bug that caused keybinding text to be narrated incorrectly.
