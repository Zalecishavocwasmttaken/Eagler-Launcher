26.40.20 is a minor release for the Bedrock Editor released on June 2, 2026.
The version number now follows Bedrock Edition instead of semantic versioning.

Contents

1 Additions
2 Changes
3 Fixes
4 References
5 Navigation

Additions
Added real-time chunk sync to the Biome Data Assignment Tool.
Changes
The Vibrant Visuals generate resource pack button now exports any edited configurations to a resource pack with a folder link provided.
Fixes
Builds no longer crash or incorrectly copy data out of the shared minecraftWorlds folder for worlds (with behavior or resource packs enabled) upon exiting the Edit Project screen using the Back / Resume buttons.
Fixed an issue where the mouse cursor preview volume vanishes after toggling Vibrant Visuals on/off.
