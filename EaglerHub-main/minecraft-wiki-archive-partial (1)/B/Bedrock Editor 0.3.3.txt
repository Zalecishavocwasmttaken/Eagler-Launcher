Bedrock Editor v0.3.3 is a minor alpha release for the Bedrock Editor released on April 12, 2023, which fixes bugs.

Contents

1 Fixes
2 References
3 Navigation

Fixes
Removed additional deprecated blocks (issue #1005824).
Fixed Molang animation not correctly pausing in Editor for guardian mobs.
Fixed Editor player dying in Tool Mode (issue #991887 (#13) and issue #991887 (#20)).
Fixed disabled command execution for /execute and command block (issue #995503).
Disabled emoting and achievements (issue #991932).
