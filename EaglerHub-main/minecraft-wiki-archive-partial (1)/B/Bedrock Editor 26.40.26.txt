26.40.26 is a minor release for the Bedrock Editor released on June 17, 2026.

Contents

1 Additions
2 Changes
3 Fixes
4 References
5 Navigation

Additions
Added a "Scale By" axis selector and a "Change Mesh" button to the Custom Mesh Tool, allowing to size the mesh along its longest, width, height, or depth axis and swap in a different mesh file without leaving the tool.
Changes
The Custom Mesh Tool now keeps the imported mesh loaded after placing or cancelling a placement, so it is possible to place the same mesh multiple times without re-importing. The mesh and preview stay ready until pressing Cancel while idle or changing the mesh.
Updated introduction floating window to be resizable.
Fixes
Fixed the cursor indicator from hiding transparent and semi-transparent blocks (e.g., water, glass, ice) behind it, which also caused a missing block in the Paste Preview at the cursor position.
Fixed a bug that caused gameplay hotbar to display in Editor tool mode.
Fixed a bug where deleting a world template locally and entering Edit World for that world caused potential data loss.
