23w13a is the second snapshot for Java Edition 1.20, released on March 29, 2023, which adds the ability to change the GUI scale during gameplay, and fixes bugs.

Changes
Items
Raiser armor trim and wayfinder armor trim

Changed textures, were offset by one pixel.
Mobs
Sniffer

No longer drops a moss block.
Gameplay
Advancements

"A Seedy Place" is now granted when planting pitcher pods.
General
Options

GUI can be scaled on the "Video Settings" screen by holding ⎈ Control and moving the  Scroll Wheel.
Tags

Added pitcher_crop to the #crops block tag.
Added potted_torchflower to the #flower_pots block tag.
Added pitcher_plant to the #tall_flowers block and item tags.
