0.0.3a is a version of Java Edition Classic released on May 16, 2009, at 18:05 UTC, which re-added caves.

Additions
World generation
Caves

Generate randomly underneath the ground.
Bugs
3 bugs reported

This version crashed for one tester.
The screen appears as white for users on an Asus Eee.
Blocks can be placed inside the space the player is currently inside.
Notes

 Notch didn't explicitly mention the "a" part in the name. However, since the previous and following versions included it, it is a safe assumption that this version's number included the "a" too.
