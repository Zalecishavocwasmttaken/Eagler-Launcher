This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.11-pre1 is the first and only pre-release for Java Edition 1.11, released on November 8, 2016. This is the final pre-release released in 2016.

Blocks
Observers

Changed the front (detecting side) texture to be an "observing face".
Same texture is used for facing up and down, although facing down: points with the top of the face toward north, and when facing up: points with the top of the face toward south.
The texture is a hybrid of the rejected observer texture () for Pocket Edition, and the previous texture.
Redstone output side now blinks when it outputs power.
Items
Enchanted books

Curse of Vanishing, Unbreaking III and Mending now appear in the tools as well as the combat tab of the Creative inventory.
General
Added a warning message for players using Java 7 or 6.
Cleaned up translation files to no longer use %d.
