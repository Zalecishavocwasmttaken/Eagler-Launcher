1.14.4 Pre-Release 7 (known as 1.14.4-pre7 in the launcher) is the seventh and final pre-release for Java Edition 1.14.4, released on July 18, 2019, which fixes some bugs and improves performance.

From 1.14.3

MC-156389 – Game crashes when pressing ⇧ Shift + ⌘ Command + ⌦ Delete to remove 18 characters at once on an anvil.
From the 1.14.4 development versions

MC-156407 – Unobtainable (speed) suspicious stew can be obtained from villagers.
MC-156574 – Villagers demand values increase/decrease indefinitely.
