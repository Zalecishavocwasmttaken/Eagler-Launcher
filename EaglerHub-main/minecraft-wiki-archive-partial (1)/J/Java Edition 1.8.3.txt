This page covers a release version that has multiple major issues under certain conditions. 
Creative mode players with modified clients can create signs that can run any command. This was fixed in 1.8.6.The dedicated server for this version includes a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.8.3 is an update to Java Edition released on February 20, 2015, to fix a bug in 1.8.2 that caused a crash on world load. 1.8.3 is compatible with 1.8 – 1.8.2 servers.
