13w09a is the eleventh snapshot for Java Edition 1.5, released on February 26, 2013.

Additions
Mobs
General

A way for mobs/entities to ride other mobs/entities.
They no longer dismount upon reload.
Mobs can now be spawned riding other mobs.
Changes
Entities
Player riding on an entity keeps it when logging off (the entity disappears along with player) and is still riding the entity upon logging back on.
General
Fonts

Fonts are now changeable.
Added HD font support.
Language

Updated language files.
Lighting

Smooth lighting can now be changed to Minimum, Maximum & Off.
Minimum uses the old smooth lighting, and maximum fixes a bug with stairs.
Texture packs

Animated blocks and items in texture packs now require the animation definition.
Fixes
11 issues fixed
From released versions before 1.5

MC-221 – Players and Mobs fall off vehicles and other ridden entities upon world reload, glitching through blocks.
MC-4009 – When a repeater is placed when facing the direction f=0 it flashes for one tick then goes off.
From the 1.5 development versions

MC-6077 – Comparators causes block updates while idle.
MC-7167 – Hopper's name doesn't change in its GUI after renamed in anvil.
MC-9391 – Command block arguments length.
MC-9404 – Comparator bug.
MC-9687 – Hopper don't update comparator when receiving item stack.
MC-10033 – Scoreboard accepts arguments for @p but if not found it will use a wrong name.
From the previous development version

MC-9788 – Mob Spawners failing to "Saving entity NBT".
MC-9935 – EntityAIAvoidEntity interference.
MC-10143 – Crash report of vanilla 13w07a shows "Suspicious classes: $Proxy3, $Proxy4]".
