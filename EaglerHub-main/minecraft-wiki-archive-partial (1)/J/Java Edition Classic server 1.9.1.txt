1.9.1 is a Java Edition Classic server version released with 0.29 on October 29, 2009.

Contents

1 Fixes
2 References
3 Navigation

Fixes
Trees now don't grow unless grow-tree is set to "true" in server.properties.
Opping and/or de-opping a player will update their status immediately without them having to relog.
