14w32d is the forty-fifth snapshot for Java Edition 1.8, released on August 8, 2014, which adds new doors and fixed a bug in 14w32c that kicked the client when joining dedicated servers.

Additions
Blocks
Wooden doors

         Added new types of doors for all the different wood types: spruce, birch, jungle, acacia and dark oak doors.
Door recipes now require all six planks to be of the same type.
Fixes
9 issues fixed
From released versions before 1.8

MC-2117 – Beacon beam not viewable on low render distance.
MC-54818 – A powered rail that should be unpowered.
MC-66316 – /list appears twice in /help 3.
From the 1.8 development versions

MC-45091 – Powered rails not updating.
MC-48797 – Blocks that are covered by barrier blocks are given 15 skylight value. Also, hostile mobs that are underneath barrier blocks still get affected by the sun
MC-59681 – Glass block has a weird texture in inventory/UI.
MC-62980 – Crash when render distance is 16 chunks.
MC-64399 – Weird arrow behavior.
From the previous development version

MC-66143 – io.netty.channel.AbstractChannelHandlerContext invokeExceptionCaught - Unable to join any server.
Trivia
14w32d was previously removed from the launcher for some time, but was added back in September 2018.
