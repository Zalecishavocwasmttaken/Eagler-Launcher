0.24_SURVIVAL_TEST_02 is a version of Java Edition Classic released on September 1, 2009, at 17:34 UTC to try again to fix a crash bug. This fix once again failed.
0.24_SURVIVAL_TEST_02 was reuploaded at 17:42 UTC (8 minutes after release) to finally fix the crash bug.
