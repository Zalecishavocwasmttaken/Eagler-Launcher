1.1 was a Java Edition Classic server version released with 0.0.16a_02 on June 8, 2009.

Additions
Added server-side support for the /say command.
Changes
Removed server-side support for the /broadcast command as it was renamed to /say.
Fixes
Fixed the "private" flag not working.
