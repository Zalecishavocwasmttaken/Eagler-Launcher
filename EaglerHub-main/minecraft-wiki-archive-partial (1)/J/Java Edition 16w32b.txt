This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

16w32b is the second snapshot for Java Edition 1.11, released on August 11, 2016 to fix some bugs and crashes from 16w32a.

Changes
Blocks
All sloped rail types

Hitbox heights are decreased from a full block to a half of a block.
Mobs
Green-robed villagers

Re-added this entity as Profession:5; its name is shown in the trading GUI as "Nitwit".
Spawns naturally in villages.
When spawned naturally in a village, or from an egg, it has no trades.
Green-robed zombie villagers

Re-added this entity as Profession:5.
Spawns naturally anywhere zombie villagers spawn.
Command format
/title can now display text in the action bar position.
