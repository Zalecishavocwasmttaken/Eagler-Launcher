1.21.11 Pre-Release 2 (known as 1.21.11-pre2 in the launcher) is the second pre-release for Java Edition 1.21.11, released on November 21, 2025.
A separate unobfuscated version of 1.21.11 Pre-Release 2 was released, titled 1.21.11 Pre-Release 2 Unobfuscated (or 1.21.11-pre2_unobfuscated when in the launcher). This is an experimental version released in preparation for obfuscation being removed from Java Edition clients and servers.

Changes
Blocks
Leaves

 The gaps between leaves are now dark green instead of black when "See-Through Leaves" video setting is disabled.
General
Graphics

Disabling the "See-Through Leaves" video setting now improves performance more than before because leaves occluded faces are now culled.
Fixes
9 issues fixed
From released versions before 1.21.11

MC-57918 – Leaves' transparent pixels no longer blend correctly on fast graphics.
MC-179383 – Leaves not culled with graphics set to Fast.
MC-238715 – The minecraft:block.chest.locked sound cannot be heard by other players when attempting to open locked blocks.
MC-303061 – The minecraft:block.chest.locked sound plays at the player's position, not the chest's.
From the 1.21.11 development versions

MC-302660 – The options.cutoutLeaves.tooltip string is missing the word "you" making it grammatically incorrect.
MC-304023 – Redundant level data fixer files are saved in a world's data folder.
From the previous development version

MC-304369 – Crash when loading the game without an existing options.txt file.
MC-304401 – Non-see-through leaves look different compared to the previous snapshot.
MC-304421 – attack_range component breaks hit result.
