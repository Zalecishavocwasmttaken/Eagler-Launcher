0.0.14a_04 is a version of Java Edition Classic released on May 28, 2009, at 17:35 UTC, which added spawn point saving and reloading using the ⏎ Return key.
0.0.14a_04 was reuploaded at 17:43 UTC, 8 minutes after release, to try and fix an issue with mouse control; this fix was unsuccessful.

Additions
Gameplay
Controls

Added spawn point saving and reloading using the ⏎ Return key.
Pressing R now sends the player back to the world's spawn point.

This version had an issue with mouse controlling.
