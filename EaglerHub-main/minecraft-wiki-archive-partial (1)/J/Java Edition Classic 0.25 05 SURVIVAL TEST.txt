This page covers a release version that has a major issue under certain conditions. 
Pressing B spawns a sign entity. The sign entity is removed in Classic 0.26. Attempting to update a world containing a sign to any version after Classic 0.26 will result in your world regenerating. You must not spawn a sign in order to update your Classic world into later versions.

0.25_05 SURVIVAL TEST is a version of Survival Test released on September 3, 2009, at 17:11 UTC. This version is not available in the launcher, but has been archived elsewhere.

General
Skins

Fixes
1 bug fixed

Monsters no longer chase after dead monsters.
Trivia
Versions _01 through _04 do not exist, per se. There are however three versions in between the original 0.25 and 0.25_05. Each patch version of 0.25 did not change the version number, which led to a wiki admin mistakenly changing the latest version listed on the wiki from "0.24_SURVIVAL_TEST_3" to "0.24_SURVIVAL_TEST_4", a version that does not exist. Notch saw this and most likely thought that he was telling him that the unlabelled patches for 0.25 should have labels and that the current version should be "_04", so Notch made the next version "0.25_05", even though under Notch's version format used at the time the version should technically have been "0.25_04".
