rd-20090515 is a pre-Classic version made on May 15, 2009, around 22:25 UTC, which adds new blocks, block picking, support for fullscreen, introduces hills and more. This was the first version to be made under the new name of the game, Minecraft: Order of the Stone.
This version was never released and is not available on the Minecraft download servers. While an entry for "rd-20090515" exists in the launcher, attempting to play it will download and launch rd-161348 instead.

Additions
rd-20090515 block and item additions
Blocks
 Cobblestone

Recycles the previous texture for rocks, although with modified contrast.
 Dirt

New block.
Generated under grass blocks.
Transforms to grass when next to a grass block.
 Planks

A new wood-type block.
Gameplay
Controls

Crosshair (+).
In this version, it was very thin.
Block picking using the number keys from 1 to 4.
The currently selected building block now displays in the top-right corner of the screen.
Fullscreen mode.
Pressing G spawns mobs.
General
Support for different block types and dynamic blocks.
A subtle layer of fog can now be seen in the distance of lit block surfaces.
Changes
Blocks
  Grass block

Texture changed from .
Now there are 3 textures - top, side and bottom
Grass blocks become dirt over time when they have no light or when a block is on top of it.
Removed the ability to place grass blocks directly.
  Stone

Texture changed from .
Mobs
  Mob

Reduced the number of mobs who spawn from 100 to 10.
Mobs who fall below level Y = -100 are now removed from the world.
Mobs now appear darker when in shade.
Non-mob entities
Player

Changed player's physics.
Now they can jump farther, walk and fall faster.
Moving is much slower when in midair.
World generation
General

Bumps may now appear, making hills and sometimes cliffs.
General
Light

Shadows have been brightened.
Technical
Level generation
Unless a level.dat from an older version is launched, the world is no longer flat.
Loading a world from older pre-Classic versions causes all blocks to become stone. This is because in earlier versions, the grass and  stone had the same block ID. Since this version added block selection, they would be converted to stone, as it kept the block ID of 1.
Trivia
This version is the version shown in the "Minecraft progress." video.
The "rd" before the version number stands for RubyDung, a game Notch was working on before Minecraft, whose codebase was later reused for Minecraft.
This is the only pre-Classic version to not use the rd-ddhhmm format, and instead uses rd-yyyymmdd.
