The list of Blocks and Items in Java Edition Classic and Indev.These values apply to blocks placed in the world in Minecraft Classic. Since versions since Minecraft Classic have drastically increased the number of blocks, and removed or re-used IDs, Minecraft Classic has its own list. IDs in  light blue cannot be legitimately obtained in the player's inventory in the game; they can only be obtained by inventory editors.​[more information needed]
