Beta 1.8 Pre-release was reuploaded/recompiled approximately 23 hours after its initial compilation, to fix several bugs and remove some debug features that were accidentally left in the game.

2 Fixes

Removals
Debug keys

Removed several debug keys that were accidentally left in the pre-reupload version.
Fixes
4 bugs fixed

From the previous development version
Villages and strongholds now generate correctly.
Fixed an issue where some models would become corrupted.
Fixed screenshots failing to save with a java.lang.IllegalArgumentException error.
Fixed the world failing to save.
Trivia
This is currently the oldest available server version to support Mojang authentication servers. This means any prior version requires setting online-mode in server.properties to false in order to join them.
