Trivia
The "rd" before the version number stands for RubyDung, a game Notch was working on before Minecraft, whose codebase was later reused for Minecraft.
When taking a screenshot with the 'Print Screen' key, it takes a screenshot of the frame that the program first showed on the screen. Each time the player runs or alt-tabs into the program, it updates that image in memory. When the player hits 'print screen', it does not take what is shown on the player's screen, but pulls it from that memory. This is true to this day if the game is fullscreened, and also can happen with other games.
