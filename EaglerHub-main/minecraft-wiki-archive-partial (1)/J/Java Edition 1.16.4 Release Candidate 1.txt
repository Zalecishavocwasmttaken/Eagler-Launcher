This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.16.4 Release Candidate 1 (known as 1.16.4-rc1 in the launcher) is the first and only release candidate for Java Edition 1.16.4, released on October 27, 2020, which fixes bugs. This is the final release candidate released in 2020.

Additions
General
Chat

Added an option to hide matched names.
Some servers send chat messages in non-standard formats. With this option on, the game will attempt to apply chat hiding anyway by matching the text in messages.

1 issue fixed

MC-202614 – Search function in social interactions screen only finds names that begin with the letters that were typed in.
