Language files
File formating changed from .lang to .json. As a result, translation strings have changed formatting:

Old formating

 gui.done=Done
 gui.cancel=Cancel

New formating

{
  "gui.done": "Done",
  "gui.cancel": "Cancel"
}

See Java Edition Flattening#Game assets for the lists of all translation keys changed
