Additions
0.31 block and item additions
Blocks
  Workbench

Pressing use on a workbench opens a 3×3 crafting grid.
Broken faster by swords.
Crafted with 4 planks.

Items
 Bowl

Used to make mushroom stew.
Crafted with 3 planks.
4
 Golden swords, axes, pickaxes and shovels

Only the golden sword is craftable, with 2 gold ingots and a stick.

 Mushroom stew

The first ever craftable food item.
Restores 8HP health.
Crafted with a bowl, a brown and a red mushroom.

Gameplay
Crafting

Added 2×2 crafting grid to the player inventory.
Changes
Blocks
Block of diamond

The crafting recipe has been changed; it now requires 9 diamonds instead of 4.

Added an unmaking recipe:
9
Changed name to "block of diamond" instead of "block of emerald".
Block of gold

The crafting recipe has been changed; it now requires 9 gold ingots instead of 4.

Added an unmaking recipe:
9
Block of iron

The crafting recipe has been changed; it now requires 9 iron ingots instead of 4.

Added an unmaking recipe:
9
 Chests

Can now be crafted with 8 planks.

Diamond ore

Is now called "diamond ore" instead of "emerald ore".
Items
Axes

Axes can now be crafted with the material on either side of the stick.
Diamond

Is now called "diamond" instead of "emerald".
Technical
General
Online saving/loading worlds is disabled
Game frame rate is limited to 60 fps.
Removals
Crafting

Removed 3×3 inventory crafting grid by pressing B.
Removed all starting house chests.
