This page covers a release version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

Trivia
1.11.2 was the last version that required Java 6.
1.11.2 was released on the latest calendar date out of all release versions in the full Java Edition release, on December 21.
At the time, 1.11.2 held the record of serving as the latest release of Java Edition for the longest time, with 168 days between its release on December 21, 2016 and the release of 1.12 on June 7, 2017.
This was later broken by the timespan between the releases of 1.12.2 and 1.13 (303 days).
This was the latest version of Minecraft without any development versions until 1.16.1.
