Alpha v1.2.4, labeled as Alpha v1.2.3_05 in game, is a version of Java Edition Alpha released on November 30, 2010, as the third part of a bug-fix update.

Additions
Gameplay
Sounds

Added proper hurt animations and sounds to mobs and players.
Changes
Blocks
Lever

Animates properly when activated.
Stone button

Animates properly when activated.
Stone pressure plate

Animates properly when activated.
Wooden pressure plate

Animates properly when activated.
Mobs
Creepers

Creepers now animate before exploding.
Explosions animate properly.
Skeletons

Skeletons now shoot their arrows way above their heads, rather than from inside their heads.
This leads to a skeleton's arrows firing further than before, but now if a skeleton were to stand in a 2 block tall space. The arrows will spawn inside the blocks above the skeleton, and immediately collide with them.
Gameplay
Multiplayer

The multiplayer join server screen now remembers the latest entered IP.
General
Increased chunk saving frequency on the server.
The player can now see sneaking players. Names of sneaking players aren't visible through walls, and are visible at a much shorter distance.
Fixes
9 bugs fixed

Leaving sneak mode no longer rapidly plays all the step sounds that it silenced during the sneak.
Swords and other weapons now deal damage properly.
Fixed dead players logging in as invisible ghosts.
Made arrows visible and deal damage.
No more infinite free arrows.
Hoes now produce proper seeds.
Server logging now appends to server.log rather than overwriting it.
Fixed minecarts and pigs moving twice as fast as they should when ridden.
Hostile mobs now correctly look up or down at their target when attacking, depending on their current elevation.
Bugs
Creepers being the only mob that spawns at night
This version had leftover debug code that caused creepers to be the only hostile mob that would spawn. This was later fixed with the release of Alpha v1.2.4_01.
