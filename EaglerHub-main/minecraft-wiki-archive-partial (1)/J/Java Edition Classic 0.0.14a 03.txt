0.0.14a_03 is a version of Java Edition Classic released on May 27, 2009 between 23:02 and 23:04 UTC to fix bugs.
Information about 0.0.14a_02 is unknown.

Fixes
5 bugs fixed

Tried fixing a bug from 0.0.13a causing players to build through blocks at certain angles.​[more information needed]
Fixed a bug upon loading maps with the first couple of versions of 0.0.14a, which was caused by a bad combination of  ProGuard and serialization.
Fixed bug that prevented players from spawning inside liquids.
Fixed bug that prevented players from building inside liquids.
Fixed a superspeed bug from 0.0.14a.
