15w47c is the forty-third snapshot for Java Edition 1.9, released on November 20, 2015 to fix some issues with 15w47b.

Changes
Blocks
Cobweb

Now drops when broken with shears.
Silk Touch is no longer required.
Fixes
19 issues fixed
From released versions before 1.9

MC-2102 – Mobs spawning inside leaves.
MC-4743 – Survival inventory not showing picked up items in Creative.
MC-16501 – Some doors in villages are backwards.
MC-17539 – /spreadplayers command doesn't teleport players out of minecarts.
MC-29294 – [Wolf pups]' heads are not centered on their bodies.
MC-29853 – Vines sometimes overwrite Jungle tree trunks.
MC-38450 – It's raining so often since 1.7.2.
MC-41215 – Shears durability doesn't decrease on dead bushes.
MC-44904 – Mobs can spawn with the same UUID as other mobs in world.
MC-61702 – @e selector in /scoreboard "operation" issues error.
MC-68265 – Rabbits continue to follow the player even once they are in breeding mode.
MC-72149 – Potion effects don't expire while Spectating mob.
MC-75217 – Rails no longer have a hitbox when there is a minecart on them.
MC-77311 – Wrong light level through covered ice.
MC-78025 – Crash when opening beacon with invalid status effect.
MC-78608 – Scoreboard selectors don't work for entities that were unloaded and then reloaded into memory.
From the 1.9 development versions

MC-92450 – Teleporting in survival or adventure mode by an active repeating command block to a location that has no supporting blocks under it will kick the player by floating too long.
From the previous development version

MC-93000 – Skin transparency issues/skin turns into a transparent skin above y:125 (in/above cloud).
MC-93001 – Unable to obtain cobwebs.

Trivia
15w47c was previously removed from the launcher for some time, but was added back in September 2018.
15w47c features a glitch with the Ender Dragon respawn code. Because of this, bedrock became obtainable in Survival mode.
