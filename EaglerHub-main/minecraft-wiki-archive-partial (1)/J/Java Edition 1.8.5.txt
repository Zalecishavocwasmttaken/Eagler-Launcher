This page covers a release version that has multiple major issues under certain conditions. 
Creative mode players with modified clients can create signs that can run any command. This was fixed in 1.8.6.The dedicated server for this version includes a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.8.5 is a minor update to Java Edition which was released on May 22, 2015 to fix a security related issue, a scoreboard related issue and some changes to splashes. 1.8.5 is compatible with 1.8 – 1.8.4 servers.

"Happy Birthday ez!"

Fixes
5 issues fixed
From 1.8

MC-50550 – Stacked boats floating.
From 1.8.4

MC-79632 – Phantom custom player in scoreboard/UUIDs of non-player entities on scoreboards truncated after relog.
Private issues

MC-80478 – Better server validation for movement packets.
MC-80479 – Invalid beacon effects are not validated.
MC-80480 – Certain attribute values are not bound.
