Additions
Command format
doDaylightCycle

Added new gamerule for daylight cycle.
Stops time relative to day changing from incrementing, pausing the sky in place.
Changes
Items
Spawn eggs

Now work on water.
Skis

Removed the skis texture, which was a red herring added by Dinnerbone in 12w50a.
Mobs
Spiders

Now have a chance to spawn with potion effects.
Non-mob entities
Fireball

The texture of the fireball was accidentally changed to
General
Resource packs

The game now uses resource packs instead of texture packs.
The Texture Ender was released to convert 1.5-compatible texture packs into resource packs.
Game directory

Renamed the game directory parameter for the game's main class (net.minecraft.client.main.Main): from --workDir to a more adequate --gameDir.
Sounds

The level-up sound is shortened from  to .
Fixes
11 issues fixed
From released versions before 1.6.1

MC-1126 – Server command "/whitelist list" doesn't display the full list of players.
MC-1202 – Mobs spawn and then quickly despawn in peaceful. Looks like the "ender-porting-out-of-water" effect.
MC-2097 – Players can't get "The End?" achievement.
MC-2419 – Persistence required tag freezes mobs.
MC-2692 – Hard to spawn squids.
MC-15732 – Achievement "We Need to Go Deeper" rewarded for going through an end portal.
From the 1.6.1 development versions

MC-11199 – Eye of ender does not always lead to the nearest stronghold.
MC-14690 – ScoreBoard health objective crashes game.
MC-15058 – Scoreboard "health" objective set to display "belowname" disconnecting player on multiplayer with end of stream.
MC-16149 – Lava texture animation moves too fast/animated textures ignoring text files.
From the previous development version

MC-17573 – Witches targeting themselves under certain circumstances.
