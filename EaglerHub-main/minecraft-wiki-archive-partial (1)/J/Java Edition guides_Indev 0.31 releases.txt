Gameplay
New

Name
Description

Crafting

Player can now use items to craft new types of items.

Inventory

Player now has a hotbar and an inventory containing storage slots, armor slots and crafting slots, enabling players to carry more than one type of item at once.

Lighting

There are now many different possible light levels, determined by time of day and proximity to light sources.

Smelting

Player can now use a flint and steel to smelt ores.

Third-person view

Pressing F5 toggles third-person view.
