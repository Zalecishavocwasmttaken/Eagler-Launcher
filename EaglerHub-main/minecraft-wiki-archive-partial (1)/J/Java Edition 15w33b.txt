15w33b is the eighth snapshot for Java Edition 1.9, released on August 12, 2015, to fix some bugs and crashes from 15w33a.

Changes
General
Pick block

Now works on Survival for items that are in the player's inventory, but not in their hotbar.
Fixes
14 issues fixed
From released versions before 1.9

MC-40452 – Missing "pack.mcmeta" on Mac OSX.
MC-47080 – Spectators count as "players" for purposes of sleeping in SMP.
MC-48621 – Regular Pick block after ⎈ Control and PB selects the block with data in it.
MC-50304 – Experience orbs too low to the ground.
MC-51984 – Picking blocks in Creative replaces enchanted tools in hand.
MC-74234 – Inconsistent ⎈ Control plus pick-block behavior.
MC-79710 – Pick block moves items and removes their nbt.
MC-80863 – Pick block not exchanging items on Survival.
From the 1.9 development versions

MC-85109 – Brewing Stand Block Model size of a full block.
From the previous development version

MC-85285 – Entities removed from world unless in minecarts.
MC-85837 – Crash or chunk corruption on turning "text" into components.
MC-85839 – Crashing when summoning a mob.
MC-85869 – Command block previous output broken.
MC-85884 – Lingering potion shows incorrect time values.

Trivia
15w33b mistakenly uses the same data version as 15w33a.
This version was previously removed from the launcher for some time, but was added back in September 2018.
