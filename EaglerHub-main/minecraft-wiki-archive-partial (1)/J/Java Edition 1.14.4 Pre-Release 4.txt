1.14.4 Pre-Release 4 (known as 1.14.4-pre4 in the launcher) is the fourth pre-release for Java Edition 1.14.4, released on July 10, 2019, which modifies server permissions and fixes bugs.

Additions
General
server.properties

Added function-permission-level to server.properties which controls which permission levels functions have.
Changes
Mobs
Pillagers

Changed arm texture.
Command format
/forceload and/reload

Now available up to permission level 2.
Fixes
9 issues fixed
From 1.14

MC-145769 – Villagers are not shutting doors behind them.
MC-148613 – Aquatic mobs are not spawning./Fish spawned from buckets count towards the aquatic mob cap again.
From 1.14.1

MC-152908 – When a player joins a server, everything that happened during the time offline queued on connecting to the server.
From 1.14.2

MC-153749 – Trusting foxes attack player when self-injured.
MC-153852 – Concrete powder deleting waterlogged blocks when falling.
From 1.14.3

MC-156013 – Breaking blocks "re-appear" to nudge player
MC-156395 – Villagers use job site blocks already in use
Private issues

MC-153406 – Score JSON component crash in items.
MC-155711 – Functions capable of running commands they should not be able to (publish, debug …).
