This is a list of Java Edition 1.1 development versions.

 11w47a
11w47a is the first snapshot for Java Edition 1.1, released on November 24, 2011, which fixed a bug and optimized the game. This is the first snapshot released in 2011, the first snapshot for Java Edition in general, and the first to use this naming format.

Changes
Optimizations

Subtle code optimizations.
Fixes
1 bug fixed

Fixed a bug with double doors where one may not open correctly.
 11w48a
11w48a is the second snapshot for Java Edition 1.1, released on December 1, 2011, which modifies farmland, apple drop chances, and void fog.

Changes
Blocks
 Farmland

Farmland can now only be trampled if the player jumps/falls on it; walking no longer affects it.
Mobs can similarly trample farmland by jumping on it, but not by walking.
Items
 Apples

Now have a 1⁄200 (0.5%)  chance of dropping from oak leaves.
World generation
Taiga

Changed temperature value from 0.3 to 0.05, making taigas generate with snow again.
Gameplay
Void fog

Void fog has been removed in Creative mode.

 11w50a
11w50a (mislabeled as 11w49a in-game) is the fourth snapshot for Java Edition 1.1, released on December 15, 2011, which adds new splashes and makes more music discs obtainable in Survival, more specifically dropped by creepers. This is the final snapshot released in 2011.

 12w01a
12w01a is the fifth and final snapshot for Java Edition 1.1, released on January 5, 2012, which adds beaches and the superflat world type as well as more language translations. This is the first snapshot released in 2012.

World generation
Superflat

Completely flat world composed of grass blocks, dirt, and bedrock; also generates villages.
World types

Re-added world types after being removed in Infdev.
The "World Type" button now functions.
Currently the only types are "Default" and "Superflat".
 Biomes

Re-added beaches as biomes, after being removed in Beta 1.8.

Frozen variant of oceans, that generates around snowy plains biomes with frozen rivers and is the same depth as regular oceans.

Generates at edges of extreme hills.

Hills variant of forests.
TaigaHills
Hills variant of taigas.
