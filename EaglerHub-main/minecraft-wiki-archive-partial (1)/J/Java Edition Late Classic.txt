Late Classic refers to six versions of Java Edition Classic released from October 27 to November 10, 2009 (0.28 through 0.30). It is a continuation of Middle Classic, occupying the same applet page on Minecraft.net. These versions are all in Creative mode, but Survival mode can be enabled in all versions by modifying Minecraft.class in minecraft.jar. This era slightly overlaps Survival Test, as the last version in Late Classic, 0.30, has a Survival mode variant, which is the final version of Survival Test. This phase concludes Classic, with the following development phase, Indev 0.31, building off of the Survival variant of 0.30.
