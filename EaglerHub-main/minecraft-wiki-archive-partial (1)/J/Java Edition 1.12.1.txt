This page covers a release version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.12.1 is a minor update for Java Edition released on August 3, 2017, which fixes bugs. It is not compatible with 1.12 servers.

Changes
General
Game credits

Updated game credits to include more Mojang staff.
Credits scroll 50% faster when viewed directly from the menu screen than through the End Poem.

Trivia
This is the final version of the unsubtitled game as the next version succeeding it, 1.12.2-pre1, is subtitled Java Edition.
This version came exactly seven years after Alpha v1.0.15.
