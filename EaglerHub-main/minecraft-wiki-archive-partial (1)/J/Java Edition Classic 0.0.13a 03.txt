0.0.13a_03 is a version of Java Edition Classic released on May 22, 2009, at 18:13 UTC, which made some changes and fixes a bug on level saving.
A version of 0.0.13a_03 repackaged with signature files from 2013 is available in the launcher. It is bit-for-bit identical aside from signature files with no difference in gameplay.
It is not known if versions 0.0.13a_01 and 0.0.13a_02 existed.
