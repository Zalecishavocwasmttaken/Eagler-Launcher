A version of Indev 0.31 was released on January 29, 2010, at 21:29 UTC, which fixed a bug with mouse and keyboard focus on Linux.

Fixes
Attempted to fix focus bug with mouse and keyboard when fullscreen mode switching on Linux.
Bugs
1 bug reported

The game has "Unable to validate certificate chain" bug.
