This page describes content that has been removed from Minecraft. 
This feature was present in earlier versions of Minecraft, but has since been removed.



This feature is exclusive to Java Edition. 

The list of Blocks and Items in Java Edition Classic and Indev.These values apply to blocks and items in Java Edition Indev 20100223, the last version of Minecraft Indev. Since versions since this have drastically increased the number of blocks and items, and removed or re-used IDs, it has its own list. Items with IDs in  light blue cannot be legitimately obtained in the player's inventory in the game; they can only be obtained by inventory editing.
