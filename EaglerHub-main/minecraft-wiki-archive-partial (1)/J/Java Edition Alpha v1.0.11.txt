Alpha v1.0.11, also known as Seecret Friday 6,  [sic] is the sixth seecret update and the fourth of Java Edition Alpha, released on July 23, 2010. It added many new items and blocks, the slime, and made other changes.

Additions
Alpha v1.0.11 block and item additions
Blocks
 Clay

Generates near water bodies.
Drops 4 clay balls when destroyed.
Can be crafted from 4 clay balls in a 2×2 crafting area.

 Reeds

Can be found next to beaches.
Can grow up to 3 blocks tall.
Items
 Book

Crafted from 3 paper in a column in the workbench.

 Brick

Obtained from smelting clay balls.
 Clay ball

4 are dropped when a clay block is broken.
 Paper

Crafted from 3 reeds in a row in the workbench.
3
 Slimeball

Dropped by the smallest slimes, however, it currently has no use.
Mobs
 Slime

A hostile mob which splits into smaller slimes upon death.
There are three sizes: small, medium, and big.
Splits only when killed by the fist and not with swords.
Spawn only below Y=32.
Big has: 16HP × 8, Medium has: 4HP, Small has: 1HP.
Changes
Blocks
Bookshelves

Are given a crafting recipe, crafted from planks and books, making them obtainable legitimately again.

Mining it drops nothing.
 Bricks

Texture changed from .
Are given a crafting recipe, crafted from brick items in a 2×2 crafting area, making them legitimately obtainable again.

They break faster with pickaxes.
The tier of the pickaxe doesn't affect the speed at which the bricks are mined.
 Cactus

Texture and model changed from .
Cacti now causes damage to mobs only if they touch it or collide with it.
Cacti can now only be placed on sand.
Can no longer be placed directly next to blocks.
Placing blocks next to cacti now destroys it.
Items
General

Player's held items display differently from the third person.
Milk bucket

Milk can now be obtained by using a cow with a bucket.
Shovels

All shovels except for wooden now destroy snow layers instantly.
World generation
General

Added clay blocks to the terrain generator.
Added reeds to the terrain generator.
Changed the generation of trees.
Changed the generation of flower patches.
Trivia
This was the only Java Edition release ending in .11 until Java Edition 1.21.11, which released over 15 years later.
