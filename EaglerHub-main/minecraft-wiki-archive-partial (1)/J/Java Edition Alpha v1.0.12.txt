Alpha v1.0.12 is a version of Java Edition Alpha, released on July 26, 2010, that made some changes relating to slimes and fixed some bugs. It also progressed the development of multiplayer.

General
Pause menu

Removed the two dots at the end of "Save and quit to title..".
Multiplayer

Render distance is now a server-side option.
Added a maximum player capacity option.
Chat now has word wrapping.
Splash

Removed splashes.txt.
As a result, the splash always displays as "missingno" (with the exception of special splashes that existed before).
Fixes
5 bugs fixed

Big slimes no longer spawn on Peaceful.
Fixed slime targeting and attacking.
Fixed font colors being broken.
Fixed a memory leak in multiplayer.
Fixed a lighting bug.
