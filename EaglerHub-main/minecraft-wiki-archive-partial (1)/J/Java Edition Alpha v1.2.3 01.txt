Alpha v1.2.3_01 is a version of Java Edition Alpha released on November 24, 2010, to fix bugs.
This version was reuploaded two minutes after release, without gameplay changes. The only difference between the two are in the signature files, specifically MOJANG_C.DSA.

Fixes
2 bugs fixed

Fixed a bug in singleplayer mode where the game would crash when trying to load a newer version, but when the player was in the overworld.
Fixed infinite looping by disabling leaf decay.
Trivia
The pre-reupload of this version and 0.25 SURVIVAL TEST are the shortest-lived versions of Minecraft, having been available for only 2 minutes.
The pre-reupload is labeled by Searge as "1.2.3_01a", while the reupload is labeled by him as "1.2.3_01b".
