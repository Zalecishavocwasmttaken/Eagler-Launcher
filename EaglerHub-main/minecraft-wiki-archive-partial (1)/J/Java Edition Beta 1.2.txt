Beta 1.2 is a version of Java Edition Beta released on January 13, 2011, that added charcoal, note blocks, dyes, squid, sugar, dispensers, lapis lazuli, bone meal, and sandstone, as well as changing and fixing other features. This is the first version released in 2011.

Fixes
