This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

Additions
World generation
Woodland mansions

Have a new room with lava encased in glass and obsidian, with a diamond block in the middle.
Gameplay
Death messages

"<player|mob> was squished too much", when suffocated due to the maxEntityCramming gamerule.
Evocation fangs

Added the [NBT Compound / JSON Object] Owner tag.
Changes
Fishing rods

Now cast out or reel in when right clicking on fences.
Loot tables

Villagers, vexes and ender dragons are now able to draw from their own loot tables.
Observers

Arrows on the top and bottom sides now point towards its output.
Vexes

Can now cross nether and end portals, and move in water.
Redstone

Air is no longer given a block update when a redstone current travels through it.
