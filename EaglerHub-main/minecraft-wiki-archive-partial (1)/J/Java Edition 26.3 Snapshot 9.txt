26.3 Snapshot 9 (known as 26.3-snapshot-9 in the launcher) is the ninth snapshot for Java Edition 26.3, released on August 17, 2026, which tweaks the teleportation of entities, makes technical changes, and fixes bugs.

Number providers

Added minecraft:product
Fields:
operands – a list of numbers as an inline value, a single namespaced ID, a list of namespaced IDs, a list of inline values, or a hash-prefixed tag ID of a minecraft:number_provider type.
Returns the product of the operands, multiplying them all together.
Requires at least one operand.
Added minecraft:minimum
Fields:
operands – a list of numbers as an inline value, a single namespaced ID, a list of namespaced IDs, a list of inline values, or a hash-prefixed tag ID of a minecraft:number_provider type.
Returns the minimum value of the operands.
Requires at least one operand.
Added minecraft:maximum
Fields:
operands – a list of numbers as an inline value, a single namespaced ID, a list of namespaced IDs, a list of inline values, or a hash-prefixed tag ID of a minecraft:number_provider type.
Returns the maximum value of the operands.
Requires at least one operand.
Added minecraft:average
Fields:
operands – a list of numbers as an inline value, a single namespaced ID, a list of namespaced IDs, a list of inline values, or a hash-prefixed tag ID of a minecraft:number_provider type.
Returns the average value of the operands.
Requires at least one operand.
Tags

Block tags
Added #uncarvable
Contains blocks that carvers can never carve.
Added #dangerous_for_teleportation
Contains collection tag defining blocks that are dangerous to teleport on.
Added #cat_does_not_teleport_to
Contains blocks that cats do not teleport to.
Added #enderman_does_not_teleport_to
Contains blocks that endermen do not teleport to.
Added #shulker_does_not_teleport_to
Contains blocks that shulkers do not teleport to.
Added #consumable_does_not_teleport_to
Contains blocks that entities do not teleport to when they consume food that teleports randomly when eaten.
Empty by default.
Item tags
Added #brewing_potion_inputs
Contains items that can be placed in a brewing stand potion slot, regardless of whether they are brewing recipe inputs.
Potion tags
Added #douses_fire
Contains potions that douse fire blocks when they hit something.
Added #hurts_water_sensitive_entities
Contains potions that will hurt entities which are sensitive to water (e.g. Endermen).
Added #extinguishes_entities
Contains potions that can extinguish entities.
Added #rehydrates_axolotls
Contains potions that will cause axolotls to rehydrate.
UI

Added a "Right Click Emulation" option to the control settings on macOS, which treats ⎈ Control +  Left Mouse Button as  Right Mouse Button.
Default is set to Off.
Realms

Added render distance and simulation distance sliders to Realm configuration settings.
Changes
Mobs
Endermen

Endermen will now take damage from projectiles if they are riding something.
No longer attempt to teleport because of environmental damage while riding something.
Can no longer teleport onto bedrock.
Shulkers

Can no longer teleport onto bedrock.
Gameplay
Advancements

Visible root advancements (i.e. ones that have display field, but no parent field) must always declare background field in display structure.
Only root advancements can have background field in display structure.
General
Data pack

The pack format version is now 117.0.
GUI

The sub-headings and categories in different tabs of Options can now be focused.
Loot functions

Changed minecraft:sequence
Can now only use an inline definition in a top-level file.
Number providers

Changed minecraft:sum
The summands field was renamed to operands and now accepts an inline value, a single namespaced ID, a list of namespaced IDs, a list of inline values, or a hash-prefixed tag ID of a minecraft:number_provider type.
Now requires at least one operand.
When used in integer mode, integer mode is used for intermediate steps as well.
Slot sources

Changed minecraft:group
Can only use an inline definition in a top-level file.
