Pre-release 1.5.1 is the first and only pre-release for Java Edition 1.5.1, released on March 19, 2013. Despite the version number being identical, this version differs in code from the full release.
This pre-release was reuploaded on March 20, 2013, to fix a null pointer crash, and this reupload became the full release of 1.5.1.
