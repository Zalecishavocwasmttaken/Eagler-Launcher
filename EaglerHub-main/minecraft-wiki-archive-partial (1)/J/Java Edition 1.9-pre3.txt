Additions
Command format
Sound events

Added that were unavailable in the snapshots, that were available from 1.8.x and previous:
block.note.pling.
entity.bat.loop.
entity.cat.hiss.
entity.ghast.scream.
entity.small_slime.jump.
entity.wolf.howl.
A new sound event was added, however unused in the actual game.
entity.player.breath.
Changes
Mobs
Horses

Are less wide (now 1.3964844 blocks instead of 1.4).
General
Credits

Thomas Guimbretière is now credited, under "Game design, programming and graphics".
Samuel Åberg is now credited, under "Music and sound".
Erik Broes is now credited under "Game design, programming, and graphics", rather than "Programming".
Subtitles

subtitles.entity.magmacube.jump is changed to subtitles.entity.magmacube.squish.
subtitles.entity.slime.jump is removed, leaving subtitles.entity.slime.squish.
Fixes
13 issues fixed
From released versions before 1.9

MC-49888 – World-bundled resources pack doesn't work on the server.
From the 1.9 development versions

MC-91173 – Eyes of ender are not targeting any of the new strongholds.
MC-92079 – The "Loading World" GUI overlay allows users to switch to another world while loading another world.
MC-92444 – Certain sounds are missing a sound event name.
MC-92525 – Signs from 1.7 and previous only import the first word on each line.
MC-94394 – Black screen instead of credits, in multiplayer.
MC-96004 – Books from 1.7 and previous only import the first word written.
MC-96571 – Click & hover event buttons are offset.
MC-97225 – Subtitle mistakes and typos.
MC-97235 – Resource pack in Minecraft world save file not working.
MC-97389 – Horses are pushed into the wall when dismounted.
MC-97461 – MalformedJsonException when connecting to a 1.8.9 server with a 1.9 pre-release.
From the previous development version

MC-97491 – Monster spawner spawns entities with NBT tags and monsters with no Pos tag at the wrong position.
