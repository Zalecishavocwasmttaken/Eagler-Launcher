0.0.14a is a version of Java Edition Classic released on May 27, 2009, shortly before 22:26 UTC, which added new blocks and changes world generation.

Additions
0.0.14a block and item additions
Blocks
 Coal ore

Can be found in amounts ranging from roughly 10 to 30 in the deposit.
 Iron ore

Can be found in amounts ranging from roughly 10 to 30 in the deposit.
 Gold ore

Can be found in amounts ranging from roughly 10 to 30 in the deposit.
 Gravel

Affected by gravity.
If placed above any number of air blocks, the gravel immediately appears at the bottom.
 Leaves

Generated as a part of trees.
 Wood

Generated as a part of trees.
 Sand

Affected by gravity.
If placed above any number of air blocks, the sand immediately appears at the bottom.
World generation
 Trees

Made of logs and leaves.
Worlds

Improved level format, now supporting the ability to save entities to levels.
There is now a cap of 256 mobs that can exist in a world.
Gameplay
Controls

 Middle Mouse Button block picking support.
Only picks blocks that number keys can select.
Holding down a mouse button allows for auto-building or breaking a block every 0.25 seconds.
General
Clouds

Added clouds.
Fog

Distance fog, rather than blank areas, now controls render distance.
The fog only gets applied on lit surfaces. Blocks in the shade appear as they would in previous versions.
Distance fog rendering is now linear instead of exponential.
Create New World

Ability to choose level size.
