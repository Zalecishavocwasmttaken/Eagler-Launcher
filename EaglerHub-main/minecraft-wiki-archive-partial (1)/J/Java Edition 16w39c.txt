This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

16w39c is the ninth snapshot for Java Edition 1.11, released on September 30, 2016 to fix some bugs and crashes from 16w39a and 16w39b.

Changes
Dispensers

Now dispense boats facing the same way as the dispenser, instead of toward the dispenser.
Shulkers

Can now be spawned on the sides and bottoms of blocks through the usage of spawn eggs.
