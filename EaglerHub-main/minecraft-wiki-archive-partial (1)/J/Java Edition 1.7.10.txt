This page covers a release version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.7.10 is a minor update to Java Edition released on June 26, 2014, which made it possible for additional features to be added to Realms without the need for a Minecraft version upgrade. It is compatible with 1.7.6–1.7.9 servers.

Additions
General
Minecraft Realms

Player activity monitor.
The ability to upload one's own worlds.
Access to more server settings:
PVP: On/Off.
Difficulty: Peaceful/Easy/Normal/Hard.
Spawn protection: Off/1-16.
Gamemode: Creative/Adventure/Survival.
Spawn animals: On/Off.
Spawn monsters: On/Off.
Spawn NPCs: On/Off.
Command blocks: On/Off.
Changes
General
Minecraft Realms

All Realms-related modules were moved into a separate library.
Future additional features to Realms will not require new releases of Minecraft.
Improvements to the user interface.
Fixes
7 issues fixed
From releases before 1.7.2

MC-3256 – Memory leak when starting large TNT chain reactions.
MC-19992 – Minecraft server stores player data in case sensitive filename.
From 1.7.2

MC-39077 – Server/client performance single host.
From 1.7.4

MC-46398 – Command Blocks Realms not servers.
From 1.7.9

MC-55580 – Minecraft Realms: User will still have Operator rights after re-inviting them.
From the same release

MC-59612 – No Realms version visible - Not on screen, not in crash report.
MC-62821 – Realms envelope icon hitbox is not aligned to icon.
Trivia
This version was released on the same day as 14w26c.
1.7.10 is the first Java Edition release version to roll from single-digit to double-digit revision numbers, and the first Java Edition version since Alpha v1.0.10, four years prior.
The next such version would be Java Edition 1.21.10, released 11 years later.
