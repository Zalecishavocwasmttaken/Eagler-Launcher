0.0.9a is a version of Java Edition Classic released on May 16, 2009, at 19:15 UTC, which adds a new building mode and a counter for displaying frame rate and chunk updates, changes the resolution and fixes bugs.
Notch did not release versions 0.0.4a through 0.0.8a, if they even existed to begin with.

Gameplay
Controls

Right-click switches between placing and destroying modes.

Changes
General
Changed the game's resolution from 1024×768 to 640×480.[is this the correct version?]

Notes

 A screenshot of 0.0.9a was released an hour after Notch announced the release of a new version, which in turn was an hour after the previous version announcement (for 0.0.3a), which itself came out an hour after 0.0.2a. It is unlikely Notch released five versions without announcement in this two-hour window. Notch may have bumped the minor version to "9" to denote it being close for a public release, which would have been 0.0.10a had that version not have a major playability issue.

 This change possibly happened at least as far back as mc-161607, because it was tested that 1024x768 resolution makes the version number on the top left corner slightly stretched by a few pixels, indicating that the change happened in an earlier version.
