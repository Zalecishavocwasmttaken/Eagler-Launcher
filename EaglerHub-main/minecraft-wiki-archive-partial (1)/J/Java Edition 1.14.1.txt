This page covers a release version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.14.1 is a minor update to Java Edition released on May 13, 2019, which improves performance and fixes bugs in 1.14. It is not compatible with 1.14 servers.

Additions
General
Controls

Pressing Esc while holding F3 pauses the game without bringing up the pause menu.
Splashes

Added the following splash texts:
"Awesome game design right there!"
"Ph1lza had a good run!"
"10 years of Mining and Crafting!"
Changes
Blocks
Campfire

Can now be lit by flaming arrows.
Crafting table

Updated texture to fix incorrect planks texture.
Iron ore

Changed texture to fix miscolored pixels.
Items
Iron horse armor

Tweaked colors slightly.
Leather horse armor

Changed texture to be more consistent with the other types of horse armor.
World generation
Villages

Many structures are tweaked to have better lighting.
Village generation has slight differences from 1.14.
General
Controls

Pressing F3 + N when in Survival mode now changes the player into Creative mode, if cheats are enabled.

Trivia
This version was released 10 years after the first public showcase of Minecraft in the video "Cave game tech test ".
Notes

 This change occurred between the last development version for 1.14.1, 1.14.1 Pre-Release 2, and the full release of 1.14.1.

 Repetition used by the YouTuber _MethodZz_ in his video "Random Changes and Bad Game Design", where he criticizes Java Edition 1.14.

 Ph1lza was a player whose 5-year-long Hardcore game was ended by a baby zombie, shortly before the release of this version.

 The first version of Minecraft was showcased 10 years before the release date of this version.
