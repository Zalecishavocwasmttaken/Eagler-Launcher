Beta 1.8.1 is the last version of Java Edition Beta, released on September 15, 2011, to fix some of the bugs and crashes in Beta 1.8.

Changes
World generation
Mineshaft

Support beams in mineshafts now generate with fences instead of planks.
Fixes
2 bugs fixed

Using ⇧ Shift+ Left Mouse Button to move items into a full chest/inventory should no longer crash the game.
Using ⇧ Shift+ Left Mouse Button to move items in and out of a dispenser should no longer crash the game.
Bugs
1 bug reported

The player can hit mobs and other players from far away.
Trivia
Beta 1.8.1 was the last update in the Beta stage of the game's development.
The prereleases for 1.0.0 prior to RC1 were named Beta 1.9, as the final name had not been decided on yet. However, since they are prereleases for 1.0.0, they are not fully considered to be part of the Beta stage.
