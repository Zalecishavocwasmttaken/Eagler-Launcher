This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.13.2-pre1 is the first pre-release for Java Edition 1.13.2 released on October 16, 2018, which includes a few performance and upgrade issue fixes that were left over from Java Edition 1.13.1.

Changes
General
Improved performance of upgrading worlds.
Improved performance of turtle pathfinding.
Improved startup time.
Improved mob spawning performance.
Other general performance improvements.
Fixes
2 issues fixed
From released versions before 1.13.2

MC-91621 – Mobs repetitively despawn and respawn rapidly at high Y coordinates (causing lag).
MC-134115 – Containers next to chunk borders can lose items when upgrading.
