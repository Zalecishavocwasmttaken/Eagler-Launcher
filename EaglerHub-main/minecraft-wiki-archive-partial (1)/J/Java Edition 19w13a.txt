19w13a is the twenty-ninth snapshot for Java Edition 1.14, released on March 27, 2019, which adds the Hero of the Village status effect, changes transparent block mechanics, and modifies some splashes.

Additions
Gameplay
Status effects

Added Hero of the Village.
Occurs when a raid is defeated.
The level of the effect is equivalent to the level of the Bad Omen effect.
Lasts for approximately two in-game days, in which trades from villagers are heavily discounted.

Changes
Blocks
Some new block placements possible as of this snapshot.
Transparent blocks

Far more blocks can now be placed on the tops and sides of transparent blocks including glass, all forms of ice, glowstone, active redstone lamps, all forms of stained glass, sea lanterns, beacons, jack o'lanterns and leaves on fancy graphics.
A list of all such changes across 1.14's snapshots can be seen at Java Edition 1.14/Transparent block changes.
Mobs
Evokers

Now spawn in raid waves 5–7 instead of just the final wave.
Illagers

Can now open doors.
Raiders now move door-to-door trying to find villagers.
Celebrate if they kill all villagers in a raid.
Added a celebration sound.
Villagers

Can now ring bells.
Now run into a nearby home when a bell is rung.
Can now be traded during raids again.
Now sweat during raids.
Celebrate when a raid has been cleared, by setting off fireworks and cheering.
Baby villagers now have biome-specific skins.
When a raid is defeated, the villagers gift the player random items according to their profession:

Gameplay
Bad Omen

Can now get up to level V.
Occurs when multiple illager captains are killed.
The player only get one Bad Omen level at a time from killing a captain.
Each person that brings Bad Omen into the village leads to additional waves of raids.
Raids

All waves have now been rebalanced, with certain waves focusing on certain mobs, and early waves becoming less easy.
Now follow a set pattern of waves based on difficulty (Easy is three waves, Normal is five waves, and Hard is seven waves).
A bonus wave is added for every additional level of Bad Omen brought into a village, equivalent to the final base wave.
Higher level of Bad Omen means higher chance that enemies have enchanted weapons.
Raids now end with a "Victory" or "Defeat" message.
