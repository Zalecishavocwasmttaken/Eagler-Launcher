This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

16w42a is the twelfth snapshot for Java Edition 1.11, released on October 19, 2016 mainly to fix a bunch of bugs and crashes.

Changes
Arrows

Now have a crit tag which determines whether the arrow deals critical hit damage.
Vexes

Now do more damage - their attack damage on Easy has been increased from 3HP to 5HP, on Normal 4HP to 9HP, and on Hard 6HP to 13HP × 6.5.
