Beta 1.0.2 is a version of Java Edition Beta released on December 21, 2010, at 08:36 UTC to fix some of the bugs and crashes in Beta 1.0_01.
This version was reuploaded at 08:41 UTC for fixing a bug with starting the game, which makes the pre-reupload version unplayable.
Beta 1.0.1 does not exist; that version is instead called Beta 1.0_01.

Trivia
This version breaks the version numbering convention of Beta 1.0, seeing as other patches are numbered with "_0n", with n being the patch number. However, Beta 1.0.2 was never called Beta 1.0_02, therefore breaking the numbering convention.
This is not the only Beta patch version that does this, Beta 1.7_01 does too.
