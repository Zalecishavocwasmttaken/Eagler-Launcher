This is a list of Java Edition 1.16.5 development versions.

 1.16.5 Release Candidate 1
1.16.5 Release Candidate 1 (known as 1.16.5-rc1 in the launcher) is the first and the only release candidate for Java Edition 1.16.5, released on January 13, 2021, which addresses two critical stability issues. This is the first release candidate released in 2021.
This version was reuploaded around an hour later to change the version string from "1.16.5 Pre-release 1".
