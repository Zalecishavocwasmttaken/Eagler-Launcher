This is a list of Java Edition 1.19.2 development versions.

 1.19.2 Release Candidate 1
1.19.2 Release Candidate 1 (known as 1.19.2-rc1 in the launcher) is the first release candidate for Java Edition 1.19.2, released on August 4, 2022, which fixes an issue causing players to get disconnected with secure chat.

 1.19.2 Release Candidate 2
1.19.2 Release Candidate 2 (known as 1.19.2-rc2 in the launcher) is the second and final release candidate for Java Edition 1.19.2, released on August 5, 2022, which fixes a crash issue in the social interactions screen.
