This page covers a development version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.12.2-pre2 is the second and final pre-release for Java Edition 1.12.2, released on September 15, 2017, which fixed some bugs. This is the final pre-release released in 2017.

Trivia
1.12.2-pre2 was previously removed from the launcher for some time, but was added back in September 2018.
1.12.2-pre2 has the same protocol version as 1.12.2-pre1, which means these versions are cross-compatible with each other.
