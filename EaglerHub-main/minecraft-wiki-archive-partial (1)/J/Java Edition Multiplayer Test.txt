Multiplayer Test refers to a developmental period of Java Edition Classic that lasted from May 31 to June 8, 2009, split off of Early Classic as a development branch. As the name suggests, these versions were released mainly to implement and test multiplayer functionality.
Multiplayer Test concluded on June 8, 2009, with multiplayer being officially released by Notch onto the main game page (/play.jsp), beginning Middle Classic.
Multiplayer Test versions were available on the applet pages /mptest/ and later /mptest.jsp, hosted separately to the base game page (/play.jsp). However, opening the mptest page would overwrite the jars, causing /play.jsp to display whichever Multiplayer Test version was loaded, meaning players who had loaded Multiplayer Test were unable to roll back to Early Classic.
