This page covers a release version that has multiple major issues under certain conditions. 
Creative mode players with modified clients can create signs that can run any command. This was fixed in 1.8.6.The dedicated server for this version includes a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

Java Edition Classic server


1.8.2 is a minor update for Java Edition which was released on February 19, 2015. 1.8.2 is compatible with 1.8 and 1.8.1 servers.
This version has a bug where it causes a crash on world load. This was fixed in Java Edition 1.8.3.
This is the first version released in 2015.

Changes
Blocks
Beacons

Now ignore bedrock above them when determining a clear view to the sky.
TNT

Reverted explosion physics changes to those before the 14w31a snapshot.
Explosion force is no longer directionally biased.
Items
Carrot on a stick

Crafting one now removes all enchantments from the original fishing rod.
Mobs
 Mooshrooms

Changed mushroom model.
Ocelots

Now spawn at or above sea level, rather than at Y=63.
Squid

Now spawn below sea level, rather than at Y=63.
World generation
Dark oak trees & oak trees

Oak and dark oak branches no longer replace blocks.
Mushroom islands

Now generate with only one kind of giant mushroom, instead of brown and red.(MC-77972).
Gameplay
Spectator mode

Mobs no longer follow/attack the player in spectator mode.
General
Multiplayer

Now directly takes the player back to the multiplayer screen, instead of the title screen, when leaving a server.

Trivia
At the time, 1.8.2 had the most pre-releases of any update so far, at 7 pre-releases, which is the second-equal most pre-releases of any update.
This is broken by 1.13, which has 10 pre-releases, and equaled by 1.12, 1.14.4, 1.15, and 1.20.
1.8.2 holds the record of having the longest developmental time in a minor version, taking more than 2 months (87 days) to complete.
