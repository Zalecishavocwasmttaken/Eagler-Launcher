This page covers a release version that has a major issue under certain conditions. 
The dedicated server for this version has a security vulnerability in the Log4j library that could be used to perform a remote code execution exploit. It can be addressed by appending a certain JVM argument to the server startup command line.

1.7.4 is a minor update to Java Edition that was released on December 10, 2013, which added a new Mojang splash screen, Twitch broadcasting, and the chicken jockey. While it was not the last update to 1.7, it was the last one before the snapshots of 1.8 started. This is the final version released in 2013.
A pre-release for 1.7.4 was released on December 9, 2013; the full release of 1.7.4 differs from this pre-release, fixing a couple of bugs.

Additions
Mobs
 Chicken jockey

Consists of a baby zombie riding and controlling a chicken.
Because the zombie is riding a chicken, it cannot take fall damage.
As it is a baby zombie, it does not burn up if exposed to daylight.
Extremely rare - every baby zombie spawned has a very small chance of spawning as a chicken jockey.
 Baby zombie villager chicken jockeys consist of a baby zombie villager riding a chicken.
 Zombie pigmen chicken jockeys can spawn in the Nether.
Gameplay
Shaders

New 'Notch' shader.
General
Native broadcasting to Twitch

Microphone can be recorded too.
Twitch chat integration in the game.
Requires a graphics card with support for OpenGL 3.0, or support for framebuffer objects via an extension.
Twitch related settings

Broadcast settings:
Quality, framerate, bandwidth, send metadata, mic volume, system volume, compression, enable chat, and user filter (for the twitch chat).
Changes
Mobs
Sheep

Sheep with the custom name "jeb_" change their color, fading between all 16 wool colors.
Commonly referred to as "rainbow sheep", "disco sheep", or "Jeb sheep".
Color changes are visual effects only; does not affect wool drops.
Gameplay
Attribute

The Sharpness enchantment now affects the "attack damage" attribute.
Rideable entities

When dismounting entities, players are no longer moved as far.
Tab key

If all auto-completable options begin the same, tab fills up the beginning - example: /gamerule doM completes to /gamerule doMob.
General
Mojang splash screen

The logo has been changed so now it's red instead of red-orange, has 2 square corners, and the rounded corners are rounder. The text is now black instead of orange, the font weight is lighter (bold instead of black), and the face appears to be a custom hybrid of Insignia and Code pro.
The Mojang splash screen is now hard-coded and can no longer be changed in resource packs.

Title screen

The "Old graphics card detected" message in 1.7.4.
The "Old graphics card detected" warning message has been changed to mention OpenGL 2.0 instead of OpenGL 2.1.
Its wording has also been changed slightly, simply saying "in the future" instead of "in the far future".
Minecraft Realms

Servers now have an icon which is the face of the owner's skin.
Config screen is modified and layout is changed.
