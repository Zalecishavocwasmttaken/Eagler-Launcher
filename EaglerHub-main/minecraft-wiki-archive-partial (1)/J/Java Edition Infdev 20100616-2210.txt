General

Trivia
As of 2026, this is the latest Infdev version to be unarchived.
As this version's only change was adding the level previewer (present in a different webpage than the main game: /infdev/preview.jsp), it has the same al_version as its predecessor.
Bugs
1 bug reported

If the player opened a world in the previewer, it would corrupt the world's level.dat by deleting player's inventory.
