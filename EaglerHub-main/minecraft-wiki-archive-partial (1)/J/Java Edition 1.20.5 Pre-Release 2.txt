1.20.5 Pre-Release 2 (known as 1.20.5-pre2 in the launcher) is the second pre-release for Java Edition 1.20.5, released on April 15, 2024.

Changes
Command format
Item modifier

set_fireworks
Fields explosions and mode have been grouped together as a sub-object.
{ "explosions": <list>, "mode": <mode>, <mode-dependent fields>} becomes {"explosions": {"values": <list>, "mode": <mode>, <mode-dependent fields>}}.
explosions field is now optional, while value field inside it is now mandatory.
Gameplay
Advancements

Snip it! advancement is renamed to Shear Brilliance.
General
Background

The nether portal texture is displayed when changing dimension to or from The Nether.
The starfield is displayed when changing dimension to or from The End.
Controls

Using ⎈ Control or ⌘ Command + pick block no longer lists "(+NBT)" in the item tooltip.
Data pack

The data pack version is now 40.
Protocol

Invalid data in packets sent from a server now cause the game client to disconnect.
