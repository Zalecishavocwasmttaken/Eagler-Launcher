Invalid data value wooden slabs are item forms of the wooden slab block with damage values outside of the usual range which wooden slabs can usually be obtained in.

Obtaining
Without the use of commands, invalid data value wooden slabs are unobtainable in the last versions in which they existed without inheriting them from a prior version in which they were obtainable.

Transmutation
Block transmutation with doors can be used to obtain wooden slabs with metadata 6 to 7, and with arrows can be used to obtain blocks with metadata 6, 7, 14 and 15. These blocks can be mined in 14w21b or earlier[verify] to obtain wooden slabs with values 6 and 7.

History
Java Edition1.3.112w17a
Proper wooden slabs have been added as a replacement for what would later become the petrified oak slab. Invalid data variants exist as a consequence of how item metadata is handled.1.7.21.7
Acacia and dark oak slabs have been properly implemented, taking up metadata values 4 and 5 and making these normally obtainable. The remaining invalid values are 6 and 7.1.814w25a
 With the introduction of data-driven item models, any item with a data value outside of what is accepted by the game has no model to point to, resulting in use of the missing item model.

Invalid data value wooden slab items now place the oak slab, rather than the block with a metadata value corresponding to the item's damage.

Existing wooden slabs placed in the world with metadata 6, 7, 14 and 15 now drop the oak slab as an item, rather than the item corresponding to their metadata value.14w30a
Invalid data value wooden slabs, alongside other invalid data value items, now appear the size of a full block when held in third person or by another player or mob.1.915w31a
 The missing model's inventory appearance has changed, resulting in the appearance of invalid data value wooden slabs also changing.

The items also appear the size of a full block when held in first person and when dropped on the ground, and also appear larger than before in an item frame.1.1317w43a
 The missing texture has changed, resulting in the appearance of invalid data value wooden slabs also changing.17w47a
Numeric IDs for blocks and items have been completely removed from the game. As a result, invalid data value wooden slabs have been "removed" as they now convert into oak slab items.[verify]
