An item tag is a group of items. They are used when a recipe allows multiple different items as inputs and control many other gameplay features. See below for the use of each item tag. They can also be used when testing for item arguments in commands with #<identifier>, which succeeds if the item matches any of the items specified in the tag, and can be searched in the Creative inventory by searching #<identifier>.
The item tags are under data/<namespace>/tags/item folder of data pack.

cat_food
Stray cats approach a player holding an item in this tag within 10 blocks, allowing the player to feed and tame it. If the player turns too quickly or stops holding the fish within 6 blocks, the cat flees and does not attempt to approach the player for a few seconds. Normally, stray cats sprint away from any player within 7 blocks, and actively try to avoid players within 16 blocks.
Items with this tag can be used to feed cats. This includes stray cats for try tame, increasing their health by food.nutrition (or one, if nutrition does not exist) for cats tamed by the player and without maximum health, setting adult cats in love, or increasing the age of non-aged-locked baby cats. However, feeding tamed cats has a lower priority than changing the collar color.

[NBT List / JSON Array] #minecraft:cat_food (2 values)

horse_food
This tag affects how certain items can be used on donkeys, horses, mules and riding tamed skeleton horses.

See details:
If an item is in the below hardcoded list of items that can be fed to these mobs, then adding it to this tag will allow the item to be used on the mob as long as it does not currently have a passenger. If in this tag, then the action it performs depends on the item ID. Adding any other item to this tag will entirely disable all interactions with the mob using the item if it does not have a passenger, including riding, equipping, and sounds/animations from the mob.
Wheat heals by 2, ages up by 20, and increases temper by 3
Sugar heals by 1, ages up by 30, and increases temper by 3
Hay bales heal by 20, and age up by 180
Apples heal by 3, age up by 60, and increase temper by 3
Red mushrooms heal by 3, and increase temper by 3
Carrots heal by 3, age up by 60, and increase temper by 3
Golden carrots heal by 4, age up by 60, and increase temper by 5. They also activate love mode if the mob is an adult.
Golden apples and enchanted golden apples heal by 10, age up by 240, and increase temper by 10. They also activate love mode if the mob is an adult.
If the mob has a passenger, or the mob is a baby and the player is holding a golden dandelion in either of their hands, using any item from this tag activates love mode in adults and ages babies up by 10%.
Note: These actions only apply where applicable. For example, healing cannot be done if the mob has full health, aging up only applies to alive baby mobs, and increasing temper only applies to untamed mobs.
Furthermore, with the exception of the skeleton horse, interacting with a tamed adult while sneaking will open its inventory instead of feeding it.

Unlike most food tags, this tag does not control which items can be used to tempt horses as that is controlled by #minecraft:horse_tempt_items.

panda_eats_from_ground
Pandas can pick up items with this tag. Adult pandas will try to go after these items within a distance of up to 8 blocks on each axis.

Items in this tag cause the panda to usually stop sitting when it stops eating. See details:
When a panda is sitting and eating an item for more than 80 ticks, there is a 1⁄20 chance per tick of in order to occur: (i) If the item is in this tag and it has been eating for more than 100 ticks, the panda removes the item from its hand and stops sitting, and (ii) the panda stops eating. If a panda stops eating but remains sitting, has an item in its hand, and is not scared, it has a 1⁄80 chance per tick of resuming eating the item.
Thus, in principle, a sitting panda with an item that is not in this tag will remain sitting and eating, stop eating, eating again... However, there are three other times when the panda may still stop sitting: (i) when it takes a hit; (ii) it is worried, it isn't eating, and it is in water or isn't thundering; and (iii) it has completed its goal of searching for food in ground and sitting (which may eventually occur if it sat down in this way and not because it was fed and in this case, when it stops sitting, it will also drop the item it is holding).
Note that in this way, feeding a non-worried panda an item that is not on that tag will only cause it to stop sitting when it takes a hit.
