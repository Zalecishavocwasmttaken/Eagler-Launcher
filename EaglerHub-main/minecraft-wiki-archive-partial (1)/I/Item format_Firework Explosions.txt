This page describes content that has been removed and was only present in earlier versions of Java Edition. 
In Java Edition 1.20.5, this format has been replaced with the data component format.

[Int Array] Colors: Array of integer values corresponding to the primary colors of this firework's explosion. If custom color codes are used, the game renders it as "Custom" in the tooltip, but the proper color is used in the explosion. Custom colors are integers in the same format as the color tag from Display Properties.
[Int Array] FadeColors: Array of integer values corresponding to the fading colors of this firework's explosion. Same handling of custom colors as Colors. May be absent.
[Byte] Flicker: 1 or 0 (true/false) - true if this explosion has the Twinkle effect (glowstone dust). May be absent.
[Byte] Trail: 1 or 0 (true/false) - true if this explosion has the Trail effect (diamond). May be absent.
[Byte] Type: The shape of this firework's explosion. 0 = Small Ball, 1 = Large Ball, 2 = Star-shaped, 3 = Creeper-shaped, 4 = Burst. Other values are named "Unknown Shape" and render as Small Ball.
