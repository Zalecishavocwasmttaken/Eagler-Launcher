Maps



This section describes content that will likely be removed in a future update of Java Edition. 
This content has been removed in  development versions for Java Edition 26.3, but the full update removing it has not been released yet.


In Java Edition, the item icons for filled and explorer maps use two different textures: filled_map.png, which is the base texture, and filled_map_markings.png, which is overlaid onto the base texture and colored differently depending on the type of map. The color is defined in the minecraft:map_color component as an integer; if not defined, it defaults to  #46402E (dec: 4603950).

Filled Map:  #46402E (dec: 4603950)
Buried Treasure Map:  #46402E (dec: 4603950)
Woodland Explorer Map:  #524C44 (dec: 5393476)
Ocean Explorer Map:  #3A7265 (dec: 3830373)
Trial Explorer Map:  #C26B4C (dec: 12741452)
Village Maps; Jungle Explorer Map; Swamp Explorer Map:  #999999 (dec: 10066329)
In Bedrock Edition, pre-colored textures are instead used for each map type.

Dyed leather armor
Leather armor color codes
Main article: Dye § Color_values
The default color is  #A06540 (Dec: 10511680). This is used for leather horse armor, and leather helmet, chestplate, leggings, and boots.

Firework stars
Main article: Dye § Color_values
The default color is  #8A8A8A (Dec: 9079434). When dyes are applied, the final color is different from that used for leather armor. They do not match one to one.
