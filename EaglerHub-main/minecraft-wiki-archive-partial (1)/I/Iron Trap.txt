Obtaining
Breaking
Although the iron trap has a drop, no vanilla tool is suitable for breaking it, so breaking it with any tool has no effect. Furthermore, attempting to use Attack / Mine to order a tool to mine it does not happen, because tools mine only the blocks that they can break.
However, it is still possible to make an iron trap block drop a living iron trap with an explosion.
Using cheats, it is possible to create a tool capable of mining it by modifying minecraft:tool.rules data component. Can be add this block in #mineable/pickaxe so that it can be mined by any pickaxe (additionally, adding a tag like #needs_iron_tool prevents it from being mined by some pickaxes.)

Post-generation
If at least eight living iron bars come close together, a living iron trap forms.
It can be placed as an item in a container by approaching an alive container or using a hopper.
It can be placed as a block with build, or somehow remove the action items from the hotbar.

Usage
Living iron traps attempt to pathfind toward the nearest player. When coming in contact with a player, it spawns a cage of 25 iron bars around them, trapping them. The iron bars replace all blocks that were previously in the iron bars' positions, including otherwise unbreakable blocks.

Issues
Issues relating to "Iron Trap" are not maintained on the bug tracker because it is an April Fools' joke, and is therefore not in the newest stable version or snapshot. Issues reported there are closed as "Invalid".

Trivia
According to one of the developers, iron and copper traps are a reference to the mod SecurityCraft.
References

 "Fun fact for those of you who played the April Fools' Day snapshot 26w14a and got imprisoned by an iron or copper trap: Those are a reference to the Cage Trap in the mod SecurityCraft that I've been a part of the dev team of since long before I joined Mojang. Did you notice it?"  – @bl4ckscor3  on X (formerly Twitter), April  3, 2026
