Ice spikes are common features made of packed ice. Ice spikes only generate in the ice spikes biome.

Generation
Ice spikes are tall spires comprised of packed ice that can be found only in the ice spikes variant of snowy plains biomes. They are randomly generated beginning at ground level and tower upward.

Construction
There are two types of ice spikes: one is short and thick, and the other is tall and thin. The short spikes generate more often than the tall spikes. Short spikes are about 15 blocks tall, while tall spikes can be over 50 blocks tall.

Config
Main article: Configured feature

[NBT Compound / JSON Object] config
[NBT Compound / JSON Object] can_place_on: The block predicate that defines which blocks the spike can be placed on.
[NBT Compound / JSON Object] can_replace: The block predicate that defines which blocks the spike can replace.
[NBT Compound / JSON Object] state: The block state to use.

An example

{
  "type": "minecraft:spike",
  "config": {
    "can_place_on": {
      "type": "minecraft:matching_blocks",
      "blocks": "minecraft:snow_block"
    },
    "can_replace": {
      "type": "minecraft:matching_block_tag",
      "tag": "minecraft:ice_spike_replaceable"
    },
    "state": {
      "Name": "minecraft:packed_ice"
    }
  }
}

Trivia
Excluding amplified generation, ice spikes are one of the only world features able to naturally extend above Y=300.
