This page describes content that has been removed from Bedrock Edition. 
This feature was present in earlier versions of Bedrock Edition, but has since been removed.

items-opaque.tga in v0.14.3, the last version to actually use this file.
items-opaque.tga was a texture atlas found inside minecraft.apk used for storing textures of items.

Format
items-opaque.tga is a fixed-width 512×512-pixel file that is split into different 16×16 squares which correspond to the texture of each item found in-game.
