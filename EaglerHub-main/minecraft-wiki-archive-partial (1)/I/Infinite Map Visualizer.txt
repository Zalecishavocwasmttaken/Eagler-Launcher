This page describes content that has been removed from Java Edition. 
This feature was present in earlier versions of Java Edition, but has since been removed. This feature has never been present in other editions of the game.

The level previewer.
Infinite Map Visualizer, also known as level previewer, was a feature which was added in Java Edition Infdev 20100616-2210 as a replacement of Indev's isometric screenshot feature, but was later removed in an unknown version. It was exclusive to the applet version of Minecraft.
The level previewer was hosted on minecraft.net/infdev/preview.jsp (archive), and was removed between September 14 and 26, 2010. However, it remained in the game's bytecode until 12w18a. Following the removal of the previewer page the tool itself can still be accessed by manually creating a launcher class that will hold the visualizer applet.
