This page describes content that has been removed from Java Edition. 
This feature was present in earlier versions of Java Edition, but has since been removed.

items-atlas in 14w21b, the last version to use this file.
items-atlas was a texture atlas used by the game to store textures for items, following the deprecation of items.png
It was eventually merged with blocks-atlas to form textures-atlas.
