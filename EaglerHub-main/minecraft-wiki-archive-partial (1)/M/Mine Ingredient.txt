Obtaining
Mine Ingredients can be obtained in Survival mode by doing certain tasks. Exiting a mine with a Mine Ingredient in the inventory unlocks it in the mine crafter menu.
If a Mine Ingredient is obtained in the Hub (through commands or using the rooms behind shimmering doors), it can be obtained by right-clicking the Mine Crafter while holding an ingredient.
The mine crafter interface shows a list of all the ingredients that the player hasn’t unlocked, labeled “Undiscovered,” and every ingredient shows a hint on how to obtain them.
Specific ingredients can be obtained with this command:
/give @s minecraft:mine_ingredient[minecraft:world_modifiers={effects : [<mine_ingredient_identifier>], include_description:1b}, minecraft:world_effect_unlock={}]
where <mine_ingredient_identifier> is the identifier of the desired ingredient.

Usage
The mine ingredient is used as an ingredient in the mine crafter. Each ingredient added to a mine using the Mine Crafter alters the generation of the mine in the described way.
It is not possible to add mine ingredients to special event mines.

To obtain this without commands, the player must visit a special event with random biomes. The Mine Ingredient requires any biome with the #minecraft:is_badlands tag, which includes only three biomes: minecraft:badlands, minecraft:eroded_badlands, and minecraft:wooded_badlands but mines other than special events can only generate with minecraft:levelN/badlands biomes, which are not included in the tag.

 As a reference to itself, it is unobtainable (bugged) due to having no.unlockedByCondition(...), however this ingredient is still counted among the requirements for The Ultimate Miner advancement. The advancement is therefore unobtainable without use of commands.

 This ingredient does not show up in the Mine Crafter in singleplayer. Even though it is not shown, it can still be obtained; when a player unlocks it, a message confirming that remains in the chat. It is also required for The Ultimate Miner advancement, making the advancement unable to be completed in singleplayer without use of commands.

 When the server-side function hurtServer is called on a player and Soul Link is active, it calls all other players' hurtServer functions as well. However, an oversight means that these calls to hurtServer also call all other players' hurtServer functions (and so on to infinity), which quickly causes a stack overflow; this means the server crashes if any player takes damage while Soul Link is active.
