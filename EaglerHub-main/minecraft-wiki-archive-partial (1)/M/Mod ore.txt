Obtaining
tile.mod_ore.0.name can be obtained only via commands.

Features
The "0" in the item's nickname "tile.mod_ore.0.name" can be changed depending on the data value.
If the item's data value exceeds "32767 (short type)", it continues to reset to "0".
Using /setblock and /fill does not affect the "0" in "tile.mod_ore.0.name".
When placed in older versions, it may create a transparent black square with other blocks or with that block.
When placing the block, the texture of a gold block appears, but after 0.1 seconds it changes to the update_block texture. Using the /setblock command with tile.mod_ore.0.name allows the gold block texture to be displayed. However, when the block is placed normally (not through modpc), the texture displayed is the update_block texture.
When the block appears with the "unknown" texture and the player moves, the original movement speed is reduced. However, when the block appears with the "golden_block" texture and the player moves, the normal movement speed is not affected.
