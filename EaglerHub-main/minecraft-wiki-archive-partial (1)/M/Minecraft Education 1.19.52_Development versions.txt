This is a list of Minecraft Education 1.19.52 development versions.

Education Edition 1.19.50.0
1.19.50.0 is the first beta version for Minecraft Education 1.19.52, released on December 1, 2022, which adds features from The Wild Update.

Additions
Main articles: Bedrock Edition 1.19.0, Bedrock Edition 1.19.10, Bedrock Edition 1.19.20, Bedrock Edition 1.19.30, Bedrock Edition 1.19.40, and Bedrock Edition 1.19.50
Added features from The Wild Update.
General
Library

Added computer science folders.
Changes
General
Library

Improved Search featuring tag search, better non-English searching, and more.
OS minimum requirement

Changed OS minimum requirement, as following:
macOS Big Sur (11.0)
Windows 8.1
iOS 11
Sign-in experience

Switching from Azure Active Directory Authentication Library (ADAL) to Microsoft Authentication Library (MSAL) for Microsoft authentication.
User experience

Easier to use tooltips and control hints in-world.
