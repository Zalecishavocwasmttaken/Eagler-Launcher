Trivia
A few mobs used to be considered variants of other mobs, but have since split off and are no longer variants, with most being given separate spawn eggs during Java Edition 16w20a, reverted before the release of Java Edition 1.10, and given separate spawn eggs again with fully separate entity ID tags in Java Edition 1.11.
Wither Skeletons and Strays used to be variants of skeletons.
Zombie Villagers and Husks used to be variants of Zombies.
Donkeys, Mules, Skeleton Horses, and Zombie Horses used to be variants of Horses.
Elder Guardians used to be variants of Guardians.
Cats used to be variants of Ocelots. Unlike the above mobs, cats were split from ocelots in Java Edition 1.14 instead of 1.11, though like the above mobs cats were given their own spawn egg during 16w20a.
