Minecraft Plus! is a screensaver app developed by Mojang Studios for April Fools Day 2021. It features many different Minecraft-themed screensavers, using block and item textures from the game, inspired by screensavers from old computers. The app can either be downloaded for free on a 64-bit Windows PC running Windows 7 or later, or used in a modern web browser.

0
Rotating block

A block with random textures on each face rotating randomly.
Similar to the loading animation in Minecraft Dungeons.

1
Lagging floating textures

A texture floats across the screen, bouncing and changing its texture when it hits the screen border. A trail is left behind the texture.

2
Floating texture

Like above, but the texture doesn't leave a trail behind it.
A reference to the bouncing DVD animation during idle modes found on many DVD players, and also bear similarities to 3D Flying Objects screensavers from Windows 95 to Windows XP.

3
Thrown items

Spinning 3D blocks and items being thrown from the center of the screen onto a rotating platform.
Up to 10 items can be visible at a time. Plants appear gray, and all spawn eggs use the default texture.

4
Water tiles

A tile grid of water.
Evokes tiled wallpaper designs from Windows 3.x to Windows 98, specifically "Red Blocks".When loaded the blocks are initially displayed in either flat colors of blue or red before water or lava textures respectively fade in.

5
Lava tiles
Like above, but with lava.

6
Menu panorama

The title screen panorama from 1.13, 1.14, 1.15, or 1.16.

7
Colored footsteps

Four tile-like footstep particles, colored red, yellow, green and blue, moving independently from each other.

8
Glow squids

Glow squids swimming to the bottom left of the screen. Regular squids may start appearing after some time.
A reference to After Dark's "Flying Toasters".

9
Bouncing item

Spinning 3D blocks and item bouncing from right to left, leaving a trail.
Similar to the winning animation in pre-Windows Vista Solitaire as well as After Dark's "Gravity".

10
Grass spread

Grass slowly spreading rightwards over dirt blocks, as the screen gradually scrolls to the right.
The spreading grass progressively changes biome color.

11
All textures

An overview of a grid with every in-game texture on it, with the camera flying and rotating over it.
The texture map features a two-color version of the creeper's face.

12
Creeper faces

Creeper faces flying towards the screen.
A reference to Windows 3.x-9x's Flying Windows, as well as Starfield Simulation.

Messages
Splash text
Random splash text is written to the browser console once the screensaver has finished loading. Some of these messages are also in Minecraft.

Splash text

Explanation

Full of stars!

Part of a quote from Dr. David Bowman ("The thing's hollow—it goes on forever—and—oh my God—it's full of stars!") and his last line before being pulled through the monolith, from the novel 2001: A Space Odyssey (while often attributed to the film of the same name, the line does not actually appear on-screen until its sequel, 2010: The Year We Make Contact). However, Minecraft is full of stars. They are square pixels on the screen that appear at nighttime.

Native performance!

Unlike Java code, Rust code is compiled to native code.

Start me up!

Refers to the Windows 95 commercial that uses the titular song by the Rolling Stones.

Pinball not included!

References how Windows Vista did not include 3D Pinball, which was originally included in Microsoft Plus! for Windows 95 and later bundled with later versions of the operating system up until Windows Vista.

Machine code!

Machine code is the earliest computer language. In reality, Minecraft Plus! was coded in JavaScript and Rust, not in machine code.

Smart pointers!

In computer science, a smart pointer is an abstract data type that simulates a pointer while providing added features, such as automatic memory management or bounds checking. Smart pointers are also a feature in Rust.

Quite finite!

Unlike the infinite Minecraft world, most scenes of Minecraft Plus! are in a finite space, except Grass spread.

Sending candy via mail!

Candy would be sent by mail, but would make it harder to be handled by post officers.

Forgettable!

Very shy!

Fast loading!

As a screensaver, Minecraft Plus! can load instantly.

Exits to desktop!

As a screensaver, Minecraft Plus! exits to desktop when a key is pressed or mouse is moved.

Stateless!

No configuration required!

Minecraft Plus! doesn't have any actual configuration options.

Batteries included!

Can be seen on battery powered gadgets.

Self-contained!

The screensaver is packaged as one .scr file and can be run by itself.

Waste of time!

Watching a screensaver is obviously considered time wasting.

Procedural generation!

In computing, procedural generation is a method of creating data algorithmically as opposed to manually, typically through a combination of human-generated assets and algorithms coupled with computer-generated randomness and processing power. World generation of Minecraft is an example of Procedural generation.

Idle game!

An Idle game is an incremental game in which clicking becomes unnecessary at some point. Minecraft Plus! can't be interacted at all, hence idle but not game.

Trivia
The box art is styled after the box of Microsoft Plus! for Windows XP, an enhancement package for the Windows XP operating system that included features such as desktop themes and screensavers. Since "Microsoft Plus!" and "Minecraft" are Microsoft branded IPs, Mojang Studios was able to use both the name and the style.
While the MinecraftPlus.scr file can be run on UNIX based operating systems with Wine, the bulk of the app does not work, as Wine's functionality as a compatibility layer does not allow it to change the OS screensaver.
The icon for Minecraft Plus! is a Glow Squid, which also appears as an animation before starting the browser version and in one of the screensavers. Since the screensaver featuring Glow Squids parodies "Flying Toasters", this may be a reference to how the Flying Toaster was After Dark's mascot.
The download for Windows contains a zip file with a .scr file inside. If the .scr file refuses to run, its extension can be changed from .scr to .exe to run it. Note that this method can also work on other screensavers as well (including the default Windows screensavers). Renaming the .scr file to .exe then running the app will open in windowed mode rather than fullscreen mode.
The app's file description, as shown on program lists, is "Minecraft Minus Players!".
The screensaver contains models and textures for many blocks and items in the game up to Java Edition 21w13a, as well as original and two-color creeper face textures.
The web page supports two query strings:
autorun, which automatically runs the screensaver if the window value is specified. If another value is specified then it just skips to the "run in fullscreen or windowed" page.
module, which, when given a positive integer, forces a specific screensaver once the screensaver is run. Each screensaver's corresponding number is listed above. It uses modulo, so numbers too high cycle back. Integers decreasing from zero follow the same order in reverse, beginning with "Glow squids" at -1, "Colored footsteps" at -2, etc. Numbers after a decimal point are ignored (truncated), and non-numbers default to 0.
In the HTML code of plus.minecraft.net, there are three comments that read "I definitely wasn’t hired for my webdev skills haha", "What is this? Where are all the libraries? This is never going to work in IE" and "Is that written by hand? Puzzling!". The text "This is never going to work in IE" means that screensaver in browser does not work at all on Internet Explorer.
