This feature is exclusive to Legacy Console Edition. 

The Legacy Console Edition versions of the game had a lot of custom music created for its many Mash-up packs and mini games composed primarily by Gareth Coker, with some earlier Mash-up pack work and likely early Battle mini game work done by C418.

The End
This music plays in the End dimension. "Boss" was added in TU9, likely in anticipation for the addition of Texture Packs. This predates the releases of the 2013 Music Update and Minecraft - Volume Beta. "The End" was added later in TU24. Unlike other editions, there is no dedicated boss music track list. However, the first track in the track list is hardcoded to play if the Ender Dragon is alive, in this case the_end_dragon_alive. If the dragon is dead, the final track in the track list is played instead, in this case the_end_end, which makes this the only track list that is not randomized. This does not apply for Texture Packs and Mash-Up Packs with custom music, so it will play any track randomly regardless of the dragon's status.

Mini Games
The mini games for Legacy Console Edition also have their own unique soundtracks, composed by Gareth Coker and C418. Each map is assigned a set of music tracks, either by using a Mash-Up pack that supports custom music, or a hardcoded TrackList for packs that don't by using the map's ThemeID. These tracks can be found in the music folder, or audio folder for Xbox 360 Edition prior to TU57, at the root of the game files. Mini game tracks that are part of a Mash-up pack can be found inside of the Data folder inside of its respective DLC folder.

Tumble

If a Mash-Up pack with custom music was used and it lacked Tumble music definition, it would default to using the Overworld music from that pack. Otherwise the default themes would play.

Trivia
Despite never being implemented, the Legacy Console Edition code references the cancelled Build Off mini game with a call for MG04_01.binka. If the game's music player state is modified to be Build Off, the game will actually search for and play the file if it exists.
Overworld music does not play in Creative mode in Legacy Console Edition.
Although never utilitzed officially, Creative mode music can be overridden via a Texture Pack/Mash-Up Pack and is used in place of the defined overworld music rather than adding to the track list. If Creative music is not defined, the game will fall back on default behavior and play the defined overworld music tracks instead.
