This page describes content that has been removed and was only present in earlier versions of Java Edition. 
This texture atlas was removed in 1.21.6.



This feature is exclusive to Java Edition. 

mob_effects.png-atlas in Java Edition 1.21.5, the last version to use this file
mob_effects.png-atlas was a procedurally-generated texture atlas used to store textures for all mob effects.
