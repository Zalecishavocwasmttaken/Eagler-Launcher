The Pan cape‌[JE  only] or The Pan Cape!‌[BE  only] is a cape given out for free to all players. The name is a pun, as the cape itself is designed to look like a stack of pancakes.

Appearance
The cape features a stack of pancakes on a white plate, covered in butter and syrup and displayed against a light blue background. The elytra design resembles a pancake when closed.

Distribution
Standard version
This cape was originally used as a placeholder to create other capes, such as the Founder's Cape.
When it first released, players who participated in Bedrock Edition's development versions (then called Minecraft Beta) were able to use the cape temporarily. Since the release of Bedrock Edition 1.16.0, this cape has been given out to all Bedrock Edition players by default.
Since May 8, 2025, the cape has also been given to all Java Edition players by default, including those who purchased the game after that date. Opening Bedrock Edition is not necessary to use the cape on Java Edition; however, there does appear to be a slight delay after purchasing the game before the cape becomes available on Java Edition.

Duplicate version
Main article: The Pan Cape! (duplicate)



This feature is exclusive to Bedrock Edition. 

There is a second version of this cape that was originally the Mojang Studios Cape. However, due to an exploit that allowed non-employees to claim the cape, its texture and name were changed to those of this cape, causing it to appear as a duplicate version of this cape in the inventory of those who claimed it. Its rarity was also changed from Legendary to Common.
Players who were able to claim the duplicated version of this cape can still equip it in the Character Creator.

Trivia
This is the only cape to be given out to all players without any known time limit.
Until the introduction of the Common Cape, the duplicate version of this cape was the only cape to have a rarity other than Legendary.
This cape was exclusive to Bedrock Edition for over five years before being made available to Java Edition players on May 8, 2025.
