This page is about planned versions of all editions of Minecraft. These updates either have major sources to their existence or have received development versions.
Only editions with known planned updates are listed here; if no known planned updates exist, the edition is left out.

Java Edition
26.3
Main article: Java Edition 26.3
26.3, the release of the third game drop of 2026, is a game drop set to release in September 2026, which adds the dappled forest biome, including red shrubs, shelf mushrooms, wool stairs and slabs, concrete stairs and slabs, straw beds, cushions, and a new abandoned camp structure.

Bedrock Edition
26.50
Main article: Bedrock Edition 26.50
26.50, the release of the third game drop of 2026, is a game drop set to release in September 2026, which adds the dappled forest biome, including red shrubs, shelf mushrooms, wool stairs and slabs, concrete stairs and slabs, straw beds, cushions, and a new abandoned camp structure.

26.60
26.60 is a minor update set to release on October 27, 2026, which introduces a native version of Bedrock Edition for the Nintendo Switch 2.
Support for Vibrant Visuals will be included in this release, unlike the original Nintendo Switch version which is backward-compatible with the Nintendo Switch 2. The render distance will also be increased from 12 to 28 chunks without Vibrant Visuals.
Together with this release, the Super Mario Mash-up, bundled with Nintendo platforms, will be updated for Vibrant Visuals.
A closed beta of this native release has been released for limited players on the Nintendo Switch 2.
