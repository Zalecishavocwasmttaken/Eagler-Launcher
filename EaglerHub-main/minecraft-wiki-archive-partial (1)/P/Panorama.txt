The panorama (also known as the cubemap) is a slowly panning wide-angle view of a Minecraft world displayed on the title screen and most other menu screens. It is themed after the latest named update and can be customized with a resource pack.

Description
The panorama is shown as a background in all menu screens that do not cover the entire background. This includes all menu screens in Java Edition and in Bedrock Edition the main menu, loading world screen (except Realms), pop-up windows, all Ore UI menus, and the Dressing Room. Non-Ore UI error screens display a static background instead.
A separate panorama is shown when Vibrant Visuals is enabled. This consists of HDR image files which are rendered with the post-processing effects from Vibrant Visuals; the default data-driven color grading settings, and the adjustable gamma, upscaling mode, and resolution. Exclusive panoramas are also shown for Minecraft Preview with Vibrant Visuals disabled and Minecraft Education.
The panorama scrolling can be adjusted with the "Panorama Scroll Speed" accessibility setting, and the "Screen Animations" video setting in Bedrock Edition also toggles panorama scrolling. A blur overlay can be adjusted in the options in Java Edition.
The panorama files in Java Edition are found in the indexes directory as multiple square images (panorama_<0-5>.png) and are extracted in the same way as sound files, as denoted in Tutorial:Sound directory. In Bedrock Edition, the regular panorama is stored in the regular vanilla resource pack in  textures/ui. Each Vibrant Visuals panorama is stored in the internal resource pack as .hdr files.



 There is a related tutorial page for this topic! 
See Tutorial:Making custom panoramas.

With resource packs, the vanilla panorama may be overwritten with custom images. Six square (1080×1080) images named panorama_<0-5>.png (or panorama_<0-5>.hdr for Vibrant Visuals) need to be placed in the  assets/<namespace>/textures/gui/title/background‌[JE  only]/ textures/ui‌[BE  only] directory. The first four panoramas are used horizontally from left to right, panorama_4 is rendered above panorama_0 and panorama_5 is rendered below the first panorama. Custom panoramas reverse the animation in Bedrock Edition by default (moving right instead of left). Several Marketplace add-ons and Minecraft Education events contain custom panoramas.

Trivia
In the Legacy Console Edition 0.66.0054.0 panorama, a second castle can be seen in the far distance. This was part of a development version of the tutorial world, which was scrapped before Minecraft's release on Xbox 360.
