Holiday Update is a name given to different Minecraft updates.

Java Edition
Java Edition 1.15, the Buzzy Bees update, released on December 10, 2019, was called a "Holiday update" in an article.
Java Edition 1.21.4, The Garden Awakens drop, released on December 3, 2024, was internally called a holiday drop/update.
Java Edition 1.21.11, the Mounts of Mayhem drop, released on December 9, 2025, was internally called a holiday drop.
Bedrock Edition
Bedrock Edition 1.8.0, released on December 11, 2018, which adds some features from Village & Pillage such as pandas, bamboo and crossbows.
Bedrock Edition 1.14.0, the Buzzy Bees update, released on December 10–11, 2019, was called a "Holiday update" in an article.
Bedrock Edition 1.21.50, The Garden Awakens drop, released on December 3, 2024, was internally called a holiday drop/update.
Legacy Console Edition
A set of updates released simultaneously across multiple platforms on December 21, 2016, which adds the outer End and new mob variants such as husks and strays:
Xbox One Edition CU36
PlayStation 3 Edition 1.38
PlayStation 4 Edition 1.38
PlayStation Vita Edition 1.38
Xbox 360 Edition TU46
Wii U Edition Patch 15
