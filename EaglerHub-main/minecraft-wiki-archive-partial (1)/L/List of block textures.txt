This page serves as a compact list of all unique block textures that exist in the current versions of Minecraft. See List of historical block textures for outdated textures.
Original texture files for Java Edition can be downloaded from https://mcasset.cloud/, and the entire default resource pack for Bedrock Edition can be downloaded from https://github.com/Mojang/bedrock-samples/releases or found in the installation files.
