This page describes content that has been removed from Java Edition. 
This feature was present in earlier versions of Java Edition, but has since been removed.



This  topic  is named by the community. 
An official name has not been given. Please update the name if confirmed by reliable sources.

The lower sky in a Buffet world in 1.13.2, with VBOs turned off.
The lower sky was a visual effect in the Overworld in which a colored plane existed below the horizon in the world, similarly to the sky opposite it. It was removed, presumably accidentally, during 1.14's development.

The VBOs toggle has been removed and are now always used. As a result, it is no longer possible to view the lower sky.
