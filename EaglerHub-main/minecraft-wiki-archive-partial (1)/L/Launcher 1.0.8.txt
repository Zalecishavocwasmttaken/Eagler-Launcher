1.0.8 is a launcher version released on July 2, July 8, and July 9, 2013. The initial release created an issue that caused Java Edition 1.6.2 to be unplayable on Mac OS X. The second release attempted to fix the issue, but was not successful. The third release was successful in fixing the issue.

Changes
The launcher now has a high-definition icon.
Fixes
5 issues fixed
MCL-90 – Unable to play Minecraft Java Edition 1.6.2 on OS X 10.5.8 using the new launcher (invalid memory access of location).
MCL-111 – Pressing "Play" button in launcher, and quickly closing it leaves java process hanging and throws an exception.
MCL-515 – Text can overlap when resizing the window.
MCL-633 – Launcher 1.0.4 breaks the authentication system.
MCL-756 – New launcher won't launch previous versions of Minecraft Java Edition, especially 1.5.2 on OS X.
