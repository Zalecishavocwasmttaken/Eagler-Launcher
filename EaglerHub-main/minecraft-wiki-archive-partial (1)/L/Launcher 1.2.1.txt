1.2.1 is a launcher version released on August 2, August 6, and August 7, 2013.

Contents

1 Additions
2 Fixes
3 Navigation

Additions
Added a warning about using Beta, Alpha, and snapshot versions.
Added Alpha versions.
Five old versions from Classic and pre-Classic have been added to the launcher.
Fixes
4 issues fixed
MCL-464 – Unexpected exception refreshing version list and "Play" button is grey.
MCL-1262 – Launcher does not remember last used profile.
MCL-1395 – Release versions 1.0 and 1.1 aren't available.
MCL-1403 – 1.5 does not launch and instead shows a error " java.lang.ClassNotFoundException: net.minecraft.client.Minecraft".
