1.6.11 is a minor update to the launcher released on January 30, 2015.

Contents

1 Changes
2 Fixes

Changes
Installer now uses Java 8.
Executable downloads its own runtime; needs to be installed.
Fixes
4 issues fixed
MCL-546 – When opening the Minecraft Launcher, it says "Unknown Publisher", instead of the game's company name, because the digital publisher signature is blank.
MCL-2987 – Launcher will not remember login info by your player name.
MCL-3128 – Launcher stuck on launcher.pack.lzma download.
MCL-3303 – Launcher doesn't open.
References

 "Our new installer uses Java 8, so that helps, but we haven't pushed people to use that - only new players have that right now."  – @Dinnerbone (Nathan Adams) on X (formerly Twitter), January 30, 2015
