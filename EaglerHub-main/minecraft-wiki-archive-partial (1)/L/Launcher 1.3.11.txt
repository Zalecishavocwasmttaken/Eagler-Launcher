1.3.11 is a minor update to the launcher released on March 12, 2014.

1 Changes

Changes
Update Notes website frame uses JavaFX if available.
Profiles are now displayed in alphabetical order.
Fixes
5 issues fixed
MCL-100 – Launcher displays a malformed page when Tumblr is down.
MCL-226 – Launcher waits before the webpage is loaded before becoming usable.
MCL-243 – Launcher not showing update notes and instead showing random symbols.
MCL-1917 – Launcher downloads pre-releases as releases instead of snapshots.
MCL-2237 – Profiles not organized in the launcher.
