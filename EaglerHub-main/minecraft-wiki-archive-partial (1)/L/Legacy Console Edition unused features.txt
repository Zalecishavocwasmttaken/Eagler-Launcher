This article is about unused features in Legacy Console Edition.   For removed features, see Legacy Console Edition removed features.



These features are exclusive to Legacy Console Edition. 

Since the beginning of Minecraft's development, numerous features have been added that are inaccessible and have no actual use. Legacy Console Edition contains a wide variety of such features, namely remnants from other editions, leftover debug material utilized during development and other scrapped elements.

Blocks
Command blocks
Main article: Command Block
All three variants of the command block are obtainable solely via external inventory editors, as opposed to Java Edition and Bedrock Edition, where command blocks are easily accessible through cheats. They are completely stripped from any in-game functionality, lacking a corresponding GUI and the ability to run commands. The game still calls on and applies the textures accordingly which seems to imply command blocks were functional in development builds of the game and used by 4J Studios. Several functions and NBT data relating to opening and using command blocks as well as for running many different types of commands are also present in the game data. Equally inoperative conditional variants are acquired by incrementing a command block's data value.

The blocks' descriptions state "Used to execute commands."

Barrier

Main article: Barrier
A barrier is a solid and invisible block, only obtainable through inventory editing. It mostly behaves like its Java Edition counterpart, aside from casting shadows like a normal block, making it moderately visible as a result. 4J Studios utilized barriers in official world templates, notably in the Update Aquatic tutorial world and various mini game maps including the glide track Shrunk. The barrier blocks have later been removed from the Update Aquatic tutorial world in Xbox 360 Edition TU73/PlayStation 3 Edition 1.82/PlayStation 4 Edition 1.83/PlayStation Vita Edition 1.82/Wii U Edition Patch 42.
Its description states "An invisible but solid block."

Wood
Main article: Wood
A block with the log's bark texture on all six sides is referred to as wood. They have multiple variants, corresponding to each wood type and their stripped forms. They are broken with an axe. Unlike in modern editions of the game, they can not be crafted into planks. Furthermore, wood is not flammable despite its appearance, although it does catch fire from lava. Furnaces accept wood as fuel.
All variants of wood have later been added as obtainable blocks in both Creative and Survival in PlayStation 4 Edition 1.90, it being the only version of Legacy Console Edition to have received the Village & Pillage update.
Their descriptions state "Chopped using an axe, and can be crafted into planks or used as a fuel."

Petrified oak slab

Main article: Petrified Oak Slab
The original wooden slab was merely another variant of the stone slab. Thus, it was not flammable and had to be broken with a pickaxe, in spite of being optically identical to a current oak slab. The spruce and birch wooden slab variants added in Xbox 360 Edition TU9 use the correct block type and do not share these traits. Jungle slabs added in Xbox 360 Edition TU12 also use the correct block type.
The petrified oak slab had finally been replaced with the proper wooden oak slab in the crafting and Creative inventory menus in Xbox 360 Edition TU17/PlayStation 3 Edition 1.07, marking it inaccessible through normal means. However, petrified oak slabs were not converted upon upgrading a world in Legacy Console Edition. Thereby, it is still possible to obtain petrified slabs by loading a save prior to TU17/1.07.
Its description states "Used for making long staircases. Two slabs placed on top of each other will create a normal-sized double slab block."

Items
debug_fourj_item
Main article: debug_fourj_item
debug_fourj_item has the texture of a barrier, no display name nor description. As its ID suggests, it was utilized during development for debugging purposes. When used on a mob, it sets that mob to be persistent. Oddly, the item texture ID barrier only applies to this item, as the actual barrier uses the block texture ID barrier.

Minecart with command block

Main article: Minecart with Command Block
The minecart with command block only exists in item form. Trying to place one down will summon a regular minecart instead. According to Java Edition and Bedrock Edition, its intended purpose was to execute commands upon interacting with an activator rail.
The game's localization data contains the unused description for this item, which states "Used to execute commands on the move!"

Spectral arrow

Main article: Spectral Arrow
Since Legacy Console Edition never received Combat Update's combat changes, the spectral arrow has gone unused. It can be shot using a bow and even has its particle trail ported over. Due to the absence of a functional Glowing effect, it acts identically to a normal arrow.
Its description states "Gives the victim a glowing outline that can be seen through blocks."

Shield
Main article: Shield
Code for the shield is present in the game data, but needs to be assigned an item form manually to be obtained in-game. Despite having a model present in the game's code, it is not seen in-game. It further lacks a texture, display name, and description. It functions like intended, absorbing most of the damage dealt to the player.
The shield was later added properly in PlayStation 4 Edition 1.90.

Tattered written book
The "Tattered" fourth generation for written books is not obtainable in standard gameplay. It can only be acquired by setting the [Int] generation tag of a written book to 3.

Entities
Giant

Main article: Giant
A giant is a 12 block tall hostile mob carried over from Java Edition. Due to its lack of AI, it will not move unless hit by a player and is never actually aggravated towards them. A giant can pick up dropped items and equip gear. It was intended to resemble a zombie, ultimately however only uses its model but not its texture file, applying arrows.png instead. It has 100HP × 50 health points and drops 5 experience points in addition to any equipped items upon death.

The Killer Bunny

Main article: The Killer Bunny
The killer bunny is a hostile variant of the rabbit, summoned by setting a rabbit's [Int] RabbitType tag to 99. In-game, it will automatically be given the custom name "entity.KillerBunny.name". It will not despawn when the difficulty is set to peaceful. It attacks nearby players, dealing 5HP damage on easy, 8HP on normal and 12HP × 6 on hard difficulty. A killer bunny becomes passive when it is lured by a player with a carrot in their hand. It has 3HP health points and the same drops as normal rabbits.
Its description states "A hostile rabbit that will attack you if you get too close! May drop a rabbit hide or a rabbit's foot when killed."

Illusioner

Main article: IllusionerAn illusioner is an unused illager from Java Edition. An illusioner attacks players, iron golems and villagers with a bow once manually equipped with one. When lacking its weapon, it becomes passive. It creates four fake duplicates when attacking, while being invisible itself. The duplicates vanish as soon as the real illusioner's Invisibility effect fades. It can also cast Blindness for 20 seconds on its victim. An illusioner has 32HP × 16 health points and can drop its bow as well as other equipped items along with 5 experience points.
Its description states "Illusioners are hostile. They attack with a bow, and use magic to confuse!"

Status effects
Glowing
Main article: Glowing
Glowing is an unused status effect that lacks functionality. It was intended to be inflicted on players or mobs hit by spectral arrows and give its victim a glowing outline that is seen through blocks.

Saturation
Main article: Saturation (effect)
Saturation is another non-functional status effect, intended to instantly replenish empty hunger points in the hunger bar. Unlike the other unused effects, it has no effect icon.

Blindness
Main article: Blindness
Blindness impairs the player's vision down to a four block radius, engulfing the rest in a thick black fog. It prevents sprinting and dealing critical hits. The aforementioned illusioner is capable of inflicting this effect.

Health Boost
Main article: Health Boost
Health Boost increases the maximum health points by four per level. The additional health is not visible in the player's health bar, whereas the health bars of ridden mobs with the effect do show it. It shares Absorption's effect icon and functions similarly, with the difference of having to regenerate the added health points manually. When the effect fades, the screen jolts as if taking damage.

Bad Luck
Main article: Bad Luck
Bad Luck is a status effect contrary to Luck. Whereas the latter is leastwise obtainable from the Creative inventory, Bad Luck goes unused entirely. It subtracts the effect level from the player's luck attribute, decreasing the chances of getting high-quality loot through fishing.

Gameplay
Hardcore mode
Main article: Hardcore
Remnants of Java Edition's Hardcore mode are still present in the game data. The mode can be unlocked by externally modifying the world data, though any leftover functionality is sparse. It locks the difficulty to hard, as any attempt to change it will result in the difficulty slider reverting back. The player's health bar remains normal and players can still respawn after death.

Build Off
Main article: Mini Games § Build OffBuild Off was a planned mini game similar to "Build Battle" on Java Edition and Bedrock Edition servers. Despite being cancelled before Legacy Console Edition was discontinued, the game's code contains multiple references to the scrapped mode. Calls for music cues as well as leaderboard functions also exist in the game data. It is implied that texture pack support for the mode was planned as texture packs have the ability to overridde the music cues for it.

A music track list, called "categories" in Java Edition and Bedrock Edition, has been programmed for the Build Off mini game and is completely functional if set to play. Sound loops
The four unused audio loops from C418's early Java Edition sound tests existed in Xbox 360 Edition's resident.xwb sound bank file as early as 1.66.0033.0 until removed in TU57's audio update from XWB to Bink Audio and in the other versions of Legacy Console Edition in the Minecraft.msscmp sound bank file until removed in PlayStation 3 Edition 1.38/PlayStation 4 Edition 1.38/Xbox One Edition CU36/PlayStation Vita Edition 1.38/Wii U Edition Patch 15. These sounds were removed despite other legacy Java Edition sound effects having remained until the discontinuation of Legacy Console Edition. It was never included in Nintendo Switch Edition. The waterfall loop was extremely compressed, perhaps erroneously, in the sound banks for PlayStation 3 Edition, PlayStation 4 Edition, Xbox One Edition, and PlayStation Vita Edition until PlayStation 3 Edition 1.21/PlayStation 4 Edition 1.21/Xbox One Edition CU18/PlayStation Vita Edition 1.21. It appeared already fixed in Wii U Edition Patch 1.

Graphics
Blocks and items
Structure block textures

terrain.png contains unused textures for structure blocks. These texture resources are called on and used by the game for the structure block which implies that structure blocks were used in development builds of the game. There are also several functions relating to opening and using structure blocks in the game data.
Structure void

The texture for the structure void is impossible to see in the retail version of the game as the structure void itself is not obtainable. Structure voids are present in all versions of Legacy Console Edition and function identically to Java Edition if loaded in a structure file.
Duplicate stems

Duplicate stem textures in terrain.png are left over. This was almost certainly to split the textures used by melon stems and pumpkin stems, similar to how birch and oak leaves have been split on the atlas, although it is not clear which it was meant to be.
Placeholder textures
Several textures found in terrain.png and items.png are, by a technicality, unused due to animated textures being used for their tiles. Technically these textures are used while loading the animated textures, but disappear nearly instantaneously due to the simple nature of most animations in the game. However, they can appear for a noticeable amount of time if the animation is quite large, which is why the first frame of the animations are usually the ones used on the terrain atlas. If the animated textures are removed, these textures are displayed as any other tile on the atlas would be. By extension, this makes any tile on the atlases eligible for an animated texture, as long as the correct resource identifier is provided in the file path.
Unused shulker box overlay tile

A comparison of terrain atlases displaying the unused shulker box overlay tile
terrain.png has an unused tile which was intended to be used in texture packs as a non-tinted overlay for shulker boxes because Legacy Console Edition shulkers have tinted layers, unlike in other editions. The shulker box tile present is used for the particles that appear when breaking a block. The intended use of the unused tile can be found in the Norse Mythology Mash-Up Pack's files where the previously assumed empty space on terrain.png is filled by the top of the shulker box texture. However, the programmers erroneously did not put the tile into the game and the tile does not have a valid resource location. This results in a strange phenomenon in the Norse Mythology Mash-Up Pack where the particles of a broken shulker box appear to only be of the colored markings on the top of the shulker box, but not of the box itself.

In addition to the existing options, several more were planned to be included for Battle and Tumble. Nevertheless, these options have eventually been cut, ostensibely because they were deemed unnecessary by the developers. Their labels and descriptors have remained in the localization data.

Battle map areas

Cavern














In the large variant, an unseen village and a structure consisting of mossy stone bricks inside a river can be found next to the cavern's opening. The latter is positioned right above an ascending stairway connecting to the arena but simply serves as a set dressing and is not reachable. This implies that the stairs were initially supposed to lead up to the surface, instead of being blocked off at their top steps. A testing area with various utility blocks is set up further away, which was ostensibly used by the developers to test interaction privileges or similar in Battle.

Cove

















An inaccessible cave section is located behind the large arena's eastern rock face. It is mostly decorated and seemingly a scrapped portion of the map. Two routes of the cave connect to the eastern escarpment's midpoint and base. Both cave entrances have been sealed off with iron bars, rendering the cave partially viewable from the arena. Although the third route is a dead end, its heading and close proximity to the arena's giant skull suggest it would have led to the skull's interior. Several immured rooms are found around the cave, with one holding a chest. Another chest is found enclosed within the mountain. Neither is filled during gameplay. Two copies of the unused cave section are found beyond the arena's western escarpment. These look to be earlier versions of the cave section, lacking redstone ores and blocks. Furthermore, these copies exhibit broken block states, physical damage dealt by explosions, and cut-offs. One copy is reachable through escaping the arena by swimming up a waterfall on the western escarpment.
Crucible














The large variant conceals a second lava sea beneath the normally accessible layer of lava. Along with numerous leftover cages and an early location for the bottom high-value chest, both of which are also found underground, it hints at the possibility that the arena's floor originally extended deeper.
Temple













An entire underground section has been cut from the large variant. It is located right below the temple and would have been accessible through descending stairs at the central spawn. These are sealed off in the map's final rendition. The scrapped section seems fully finished with decoration and even a loot chest that is refilled during gameplay.
Lair

















Multiple oddities are present in the small variant. An arrow made out of quartz blocks at world spawn points into the arena's direction. The arena itself has a creeper face carved into its outer walls. Both variants have an unused room that is sealed off from the arena. Whereas the room of the small variant is empty, that of the large variant is fully decorated.
Atlantis









A few inaccessible rooms are located underground which appear to be leftovers from a once planned segment in the arena's large variant that was ultimately scrapped.
Ruin





























Both map variants contain several cut rooms and staircases which would have connected different parts of the map. Although a select few are partially decorated, they appear mostly unfinished. Furthermore, parts of the background city scenery around the arenas are heavily obscured and consequently deemed unused.
Siege









Unutilized redstone wiring is scattered throughout the small arena. They appear to have been intended for differing purposes, as, for example, a few connect to various dispensers containing splash potions of weakness, poison and slowness, whereas it is unclear what the rest has been intended for. In addition, between the two canals in the large arena which can be accessed during standard gameplay, an unfinished third canal is found.
Old tutorial world
The file of the Xbox 360 Edition TU46/Xbox One Edition CU36/PlayStation 3 Edition 1.38/PlayStation 4 Edition 1.38/PlayStation Vita Edition 1.38/Wii U Edition Patch 15 tutorial world is still stored in the game files, despite having been superseded by the Xbox 360 Edition TU69/PlayStation 3 Edition 1.76/PlayStation 4 Edition 1.76/PlayStation Vita Edition 1.76/Wii U Edition Patch 38 tutorial world.

4J Studios utilized a number of debug tools to aid during Legacy Console Edition's development.

Other
UI data DLC file
An unused DLC file type named UIDataFile that would have originally been used for UI graphics in texture packs, similarly to how other Data DLC files, usually using a .pck extension, hold other graphics for packs. Despite being unused entirely, the file type remains a valid DLC file type for DLC packs although it does nothing and all functionality has been removed. This format was replaced with Media.arc files that housed Adobe Shockwave Flash files containing UI graphics and layouts. This was until SWF files were replaced with a custom file format, named FUI, in PlayStation Editions 1.52, Xbox One Edition CU44, and Wii U Edition Patch 24. According to Steven Woodward, also known as 4JSteve, this change was made because the old format presented memory constraints in all editions and performance issues for PlayStation 3 Edition. Xbox 360 Edition used Microsoft's proprietary XUI format until switching to .fui in TU57.

Biome preview menu
The biome preview menu on Wii U Edition, as restored by user Pirlo.
An unused menu that displays a map of the seed before it is generated. The user is able to preview the biomes in the seed and each biome is given a unique, but oddly inverted, color entry. The user can also randomize the seed, zoom into the map and change the world size. The playable area of the seed can also be panned horizontally and vertically with directional inputs. The world does not generate accurately to the preview, likely due to removed code, leaving artifacts where the world would have ended if it was not shifted or scaled. The strings for this menu are translated in other languages, implying that this was a planned feature rather than a developer tool.

[String] LevelName

Leftover from Java Edition's method of storing world names.

Each Legacy Console Edition use a different method for storing save names and none are using the LevelName NBT tag. Xbox 360 Edition stores save names and thumbnails in an extensionless file named _MinecraftSaveInfo. PlayStation 3 Edition stores save names in an extensionless file named FILEINFO in a folder named <TITLE-ID>-CACHE. PlayStation 4 Edition stores the save name in a PARAM.sfo file in a sce_sys folder in the save's folder. Wii U Edition stores the save name and thumbnail of a world in a .ext file located next to an identically named, but extensionless, save file. Present in all worlds with value "world" by default.

Notes

 Interestingly, both English strings store "Castle" but most other languages present have "Castle Crashers" stored which may imply a cancelled collaboration.
