This page serves as a compact list of all unique mob and entity textures or skins in the current versions of Minecraft. See List of historical entity textures for outdated textures.
Original texture files for Java Edition can be downloaded with latest client.jar, and the entire default resource pack for Bedrock Edition can be downloaded from https://github.com/Mojang/bedrock-samples or found in the installation files.
