This article documents an April Fools' Day joke. 
This feature was exclusively part of a joke version and is not currently planned for addition to regular Minecraft.

This page serves as a compact list of all unique textures that exist in released joke versions of Minecraft. For an overview on when each texture was changed, see the appropriate History of textures subpages.
Original texture files for Java Edition can be extracted from the .jar files. They can be found in client.jar/assets/minecraft/textures.
