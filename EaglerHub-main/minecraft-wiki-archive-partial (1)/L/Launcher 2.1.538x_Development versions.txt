This is a list of Launcher 2.1.538x development versions.

 2.1.532x
2.1.5322 (Windows), 2.1.5321 (macOS), or 2.1.5320 (Linux) is a launcher beta version released on June 25, 2019, which fixed bugs and added some things.

Additions
Added more logging to track down MCL-11112 – Launcher cannot establish connection to the internet.
Added the Launcher version to the log file.
Added more icons to choose for installations.
Fixes
Fixed a news post being missing when in demo mode.
Fixed the icons of default installations being wrong.
Fixed installations added by third party software not showing up as selected on start.
MCL-11101 – Launcher crashes immediately after launch.
MCL-11003 – The installation icons still uses the old textures.
MCL-11099 – JVM Arguments aren't applied.
MCL-11137 – New launcher goes blank after login on Linux.
MCL-11145 – Unable to play the demo in the launcher, as it said that it couldn't download some game files without internet.
 2.1.537x
2.1.5373 (Windows), 2.1.5372 (macOS), or 2.1.5371 (Linux) is an update to the launcher released on June 25, 2019, which fixed bugs.

Fixes
MCL-10230: All launch settings are erased after computer hard-locks.
MCL-11002: Version list isn't in alphabetical order in the Play screen.
 2.1.53xx
2.1.5379 (Windows), 2.1.5380 (macOS), or 2.1.5381 (Linux) is a launcher beta version released on June 25, 2019, which fixed a bug, updated translated and changed some things.

Changes
Updated translations.
Changed networking settings to try to alleviate MCL-11112 – Launcher cannot establish connection to the internet.
New drop-down component to fix accessibility and selection problems.
Fixes
MCL-11002 – Version list isn't in alphabetical order in the Play screen.
