A function tag is a group of functions. They can be called in the /function command with #<identifier>, which runs all the functions specified in the tag in the order of their first appearance in a tag. If a function is referenced multiple times in a tag and its sub-tags, it is run once.
Moreover, functions tagged in the minecraft:tick tag run every tick at the start of the tick and functions tagged in minecraft:load run once at the start of the tick after a server (re)load.
The function tags are under data/<namespace>/tags/function folder of data pack.
