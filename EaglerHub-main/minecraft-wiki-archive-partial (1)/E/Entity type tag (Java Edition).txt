  This article is about the grouping of types of entities.   For grouping of individual entities, see Scoreboard § Tags.

An entity type tag is a group of entity types. It can be used in type target selector arguments and loot table conditions with #<identifier>, which checks if the entity's type matches any of the entity types specified in the tag. Entity type tags are also used to control a number of other gameplay features; see below for the use of each tag.
The entity type tags are under data/<namespace>/tags/entity_type folder of data pack.
