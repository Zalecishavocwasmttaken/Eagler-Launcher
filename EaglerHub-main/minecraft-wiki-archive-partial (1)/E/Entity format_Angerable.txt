[Long] anger_end_time: Ticks until the mob becomes neutral. Depletes by 1 every tick if the value is greater than 0 and the target is a player beyond detection radius or a mob within detection radius. Set to 0 when mob targets exit detection radius or are killed. For bees, depletes by 1 every tick for player targets regardless of detection radius, and is set to 0 when target is stung. When aggravated, value is set to a random number between 400 and 800.
[Int Array] angry_at: The UUID of the entity that caused this mob to be angry, stored as four ints.
