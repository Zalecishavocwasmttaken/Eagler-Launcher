Usage
Etho slabs behave like TNT, with the only difference being that upon explosion there is a 25% chance of spawning a falling anvil one block above the nearest player within a 20 block radius, which is a reference to EthosLab's fondness in pranking his friends with a falling anvil.

Block metadata

Bit

Effect

1 (0x1)

If this bit is set, the Etho slab is triggered on punch rather than destroyed.

4 (0x8)

If this bit is set, the Etho slab is a top slab.

Issues
Issues relating to "Etho Slab" are not maintained on the bug tracker because it is an April Fools' joke, and is therefore not in the newest stable version or snapshot. Issues reported there are closed as "Invalid".
