Description
The End sky is rendered exclusively in the End dimension. Much like the panorama, six texture planes are rendered in a cube surrounding the camera. The texture is repeated 16 times to an edge, for a total of 256 instances of the texture per face (1536 for the entire cube). It is also rotated when facing east, south and west, and mirrored when facing up, north, and west.

The texture file will always point to environment/end_sky, a pixelated noise similar to TV snow, grayscale in Bedrock Edition or tinted purple in Java Edition.

This texture is then tinted  #282828 in Java Edition, or purple​[more information needed] in Bedrock Edition.
In Bedrock Edition, this is also multiplied with the sky fog color ( #0B080C), although fog does not obstruct the End sky. The Night Vision effect brightens the fog and therefore colors it very bright purple.
With Vibrant Visuals, the End sky is colored dark purple around and below the horizon, and black at zenith. This color is rendered as atmospheric fog behind the transparent End sky texture. See here for details.
The texture itself is unaffected by air, water, and lava‌[BE  only] fog, but not ender dragon fog in Java Edition. The End sky texture is not rendered with "Beautiful Skies" disabled.

End flash
An End flash in Bedrock Edition with Vibrant Visuals
An End flash in Java Edition
The End flash is a weather-like event that occurs at random spots in the sky, at differing heights above the horizon, while a rumbling sound effect plays. There is a 30 second delay between flashes, and each flash lasts between 5 and 19 seconds, with some fading.
With Vibrant Visuals, End flashes are purple colored global directional light sources, which can produce purple illumination and reflections on objects and cast shadows in the opposite direction of the flash. Specifically, the light is colored  228, 93, 255, and its intensity is 3 lux. During an End flash, dense and purple volumetric fog becomes visible.
On classic graphics, End flashes use a purple "flash" texture, and block lighting becomes purple tinted during the flash.‌[JE  only] The texture is obstructed by ender dragon fog, leaving only the tinting and sound as tangible effects.
End flashes can be disabled in the accessibility settings. Furthermore, the flash's graphics are not visible with "Beautiful Skies" disabled, but this does not disable the sound effects.
