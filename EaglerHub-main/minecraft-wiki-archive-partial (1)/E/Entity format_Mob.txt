[NBT Compound / JSON Object] drop_chances: A map between equipment slot type and chance value. Each entry specifies the chance that the item in that slot is dropped when the mob dies. If not specified or removed, the chance defaults to 0.085f. A value in the range (0f, 1f] applies a random damage value to the dropped item, and the item is only dropped if the mob is killed by a player or tamed wolf. For values greater than 1f, the item's damage value is preserved when it is dropped, and it drops regardless of what killed the mob. When a mob picks up equipment, the corresponding drop_chances value is set to 2f. Each entry is also used to calculate the chance that the item is dropped when swapped for a more preferred one, but not directly. If the value is 0f or less, the drop chance is 0%, but if it is greater than 0f, the drop chance is the value +10% and the item damage is preserved.
