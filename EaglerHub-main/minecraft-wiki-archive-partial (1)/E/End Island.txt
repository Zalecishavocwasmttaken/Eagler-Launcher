An End island is a terrain feature made up of a roughly hemispherical cluster of End stone blocks found within its respective biome.

Generation
End island features are generated from Y=55 to Y=70 around the outer islands. The probability that an End island tries to generate in each chunk is 1⁄14. It generates successfully when in a small End islands biome‌[Java Edition  only] or at a chunk where the noise value fits‌[Bedrock Edition  only]. In Java Edition, if it tries to generate a small island in a chunk, there's an 1⁄4 probability to try to generate another small island in this chunk. The two islands often overlap with each other. In Bedrock Edition, if the chunk's noise value fits, there's also a probability of 1⁄4 to re-generate another island, but at the same position, which makes the two islands look like a single island.
End island features also generate when an End gateway spawns on the outer islands if the chunk does not provide any End stone.
