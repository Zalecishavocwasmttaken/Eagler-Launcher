[Boolean] HasBeenShot: 1 or 0 (true/false) - If true, this projectile has existed for at least one tick. This is used by the game to ensure that it only triggers the projectile_shoot game event once.
[Boolean] LeftOwner: 1 or 0 (true/false) - If true, this projectile has escaped its owner's hitbox for the first time and can now collide with entities. Not present when false.
[Int Array] Owner: The UUID of the entity this projectile was thrown by, stored as four ints. May not exist.
