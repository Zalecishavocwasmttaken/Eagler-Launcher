Explorer maps are a group of 11 premade map variants which are marked with the location of various structures.
In the third drop of 2026, four new explorer maps will be added as well as maps for abandoned camps in 8 different biomes.

Commands
In Bedrock Edition, because they are all data variants of the filled map item, they can be obtained with commands such as /give @s filled_map 1 3, but only when it can find a structure to locate. See § Metadata for a list of IDs.
‌In Java Edition 26.3​[upcoming], it is possible to obtain each map using the command /give, varying its ID; however, the maps will be empty. To obtain a map with a structure, it is necessary to use the item modifier exploration_map. Below is the complete list of commands for each map. If the structure is not found, the result will be an empty map. With the exception of the buried treasure map, new maps generated from loot or trades never point to the same structure as previous maps.

Locating structures
An explorer map shows a section of terrain that contains a specific structure, marked with a small icon. The structure shown may not be the nearest such structure to the player, the structure depends on when it is graded, where it searches for a structure according to the location of the chest or villager. For loot, the map is generated when the loot is generated (opening the chest, destroying the chest, hopper), for trades, the map is generated when the trade is generated. The structure sought is similar to the command /locate structure but with a range of 101×101 if it is generated by loot (maintain the 201×201 range if it is generated by trading), and ignore the structures that have already been found by previous maps, except for the buried treasure map.
An explorer map differs from a normal map in that it shows the area's land-water outline, with an orange striated texture for water and swamps, and the blank map texture for land.
If the player icon is smaller than it would be on a normal map, that means the player is a great distance away. When the player is less than 1027 blocks away from the map border, the icon returns to the proper size. When the player reaches the map's area of land (512×512), the map fills in like a normal map. Unlike the player icon when inside the map area, the player off-map and off-limits icons do not rotate.​[until: Third Drop 2026]
It is possible for multiple maps to point to the same treasure or structure, since explorer maps lead to the closest location (relative to where they were created) of their target type.

The output has the same map center as the input map, and the same monument, woodland mansion, buried treasure, trial chamber, village, jungle temple or swamp hut marker. Cloned maps are stackable.

The parts of the world that have already been explored and mapped are copied, and newly explored areas appear on both instances. In Creative mode, cloned explorer maps can be obtained by pick blocking on the explorer map displayed on item frames (the map needs to be out of the player's inventory when using pick block, or else that map moves into the active hotbar slot).

Item data
Java Edition:

See also: Data component format

An explorer map differs from a map in that its map_color and item_name components are set. Additionally, its map_decorations component includes an entry for its target structure. Its map item entry is identical to that of a normal map, except that by the time the player sees it, its colors byte array is pre-filled with explorer maps' characteristic land-water boundary lines and water shading.

[NBT Compound / JSON Object] components: the item's components tag.
[String][NBT List / JSON Array][NBT Compound / JSON Object] minecraft:item_name: The default name of this item, as a text component, present on all items by default. Unlike the minecraft:custom_name component, this name cannot be erased using an anvil, is not italicized, and does not appear in some labels, such as banner markers and item frames. Used in the map name depending on the structure.​[until: JE 26.3] Used in the name of the abandoned camp map depending on the biome.​[upcoming: JE 26.3]
[Int] minecraft:map_color: The color code for the minecraft:map_color color provider in item model definitions. Normally used by the minecraft:filled_map item model.​[until: JE 26.3]
[NBT Compound / JSON Object] minecraft:map_decorations: Contains key-value pairs of the icons to display on this filled map.
[NBT Compound / JSON Object] <key>: The key-value pair of a single icon, where the key is an arbitrary unique string identifying the decoration.
[String] type: The type of the icon. Can be player, frame, red_marker, blue_marker, target_x, target_point, player_off_map, player_off_limits, mansion, monument, banner_white, banner_orange, banner_magenta, banner_light_blue, banner_yellow, banner_lime, banner_pink, banner_gray, banner_light_gray, banner_cyan, banner_purple, banner_blue, banner_brown, banner_green, banner_red, banner_black, red_x, village_desert, village_plains, village_savanna, village_snowy, village_taiga, jungle_temple, or swamp_hut.
[Double] x: The X world coordinate of the decoration.
[Double] z: The Z world coordinate of the decoration.
[Float] rotation: The rotation of the icon, ranging from 0.0 to 360.0, rotated clockwise from north in degrees.
[Int] minecraft:map_id: The map data number for this item, representing the shared state holding map contents banner and item frames decoration. When present, add information to the tooltip and change the rendering of the item in hand or in the item frame for map rendering. Only maps (filled_map) and explorer maps can update map content.

Issues
Issues relating to "Explorer Map" are maintained on the bug tracker. Issues should be reported and viewed there.

Trivia
Explorer maps fill as the chunks are generated, rather than when the player holds them while in the area; leaving an explorer map while exploring the area still fills the map.
In Bedrock Edition, inventory editors and add-ons can be used to create explorer maps that lead to any structure.
