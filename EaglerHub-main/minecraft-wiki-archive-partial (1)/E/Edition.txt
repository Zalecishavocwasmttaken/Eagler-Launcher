Java Edition
Minecraft: Java Edition (formerly just Minecraft) is the original version of Minecraft, developed by Mojang Studios for Windows, macOS, and Linux. Notch began development on May 10, 2009, publicly releasing Minecraft on May 17, 2009. The full release of the game (version 1.0.0) was on November 18, 2011, at MINECON 2011. The latest release is 26.2.

Bedrock Edition
Minecraft: Bedrock Edition (only Minecraft on most platforms and in-game) refers to the multi-platform versions of Minecraft developed by Mojang Studios, Xbox Game Studios, and SkyBox Labs and based on the Bedrock codebase. The latest release is 26.45.

Minecraft Education
Minecraft Education (formerly and still commonly referred as Minecraft: Education Edition) is an educational edition of Minecraft specifically designed for classroom use. It is developed by Mojang Studios and Xbox Game Studios and has features that make Minecraft easy to use in a classroom setting. The latest version is 26.32. It is built on the same codebase as Bedrock Edition and many of its features can be accessed using world settings in Bedrock Edition.

Legacy Console Edition
Legacy Console Edition is a discontinued term that refers collectively to several nearly identical editions of Minecraft developed by 4J Studios for game consoles. It comprises of:

 Minecraft: Xbox 360 Edition (Final version: TU75)
 Minecraft: Xbox One Edition (Final version: CU59)
 Minecraft: PlayStation 3 Edition (Final version: 1.84)
 Minecraft: PlayStation 4 Edition (Final version: 2.93)
 Minecraft: PlayStation Vita Edition (Final version: 1.84)
 Minecraft: Wii U Edition (Final version: Patch 43)
 Minecraft: Nintendo Switch Edition (Final version: 1.0.16)
Legacy Console Edition introduced new features such as a simplified crafting system, in-game tutorials, leaderboards, built-in mini games and split-screen multiplayer,[except PS Vita] as well as online multiplayer for up to 4‌[PS Vita  only] or 8[Xbox 360, PS3, Wii U, & Switch only] or 16‌[X1 & PS4  only] players, which required the console's paid subscription service.[except PS3, PS Vita & Wii U] As with all editions, updates were free of charge.

China Edition
Minecraft: China Edition is a localized edition of Java and Bedrock editions for mainland China, developed by Mojang Studios and NetEase. The latest version is 1.15.28.11160 for Windows, 3.9.27.298720 for Android, and 3.9.27.298720 for iOS, iPadOS, and macOS.

Other editions
Minecraft 4k
Minecraft 4k was an edition of Minecraft developed for the 2010 Java 4K contest, where the entry games were required to be within four kibibytes (4096 bytes) in size.

MinecraftEdu
MinecraftEdu was a discontinued educational mod for Java Edition, developed by TeacherGaming, published by E-Line Media, and licensed by Mojang Studios. It was meant as an educational version of Minecraft. The final version was 1.8.9 Build 3.

Pi Edition
Minecraft: Pi Edition was a discontinued edition of Minecraft developed for the Raspberry Pi. It is based on Pocket Edition Alpha v0.6.1 but slightly cut down, containing a revised feature set and support for multiple programming languages. Pi Edition is intended as an educational tool for novice programmers. The final version was v0.1.1 alpha.

New Nintendo 3DS Edition
Minecraft: New Nintendo 3DS Edition is an edition of Minecraft developed by Other Ocean Interactive and Mojang Studios for the New Nintendo 3DS/2DS systems, but is not compatible with the original Nintendo 3DS/2DS systems. The final version was 1.9.19.

Minecraft Classic
Minecraft Classic is a JavaScript remake of Classic 0.0.23a_01, made to celebrate 10 years of Minecraft and was uploaded to the Minecraft website (built with the noa-engine library, which uses the Babylon.js library for rendering). This version can be played at classic.minecraft.net for free.
