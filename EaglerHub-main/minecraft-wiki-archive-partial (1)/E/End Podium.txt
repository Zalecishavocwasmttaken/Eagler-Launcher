The End podium (also known as the End fountain or exit portal) is a portal that enables the player to return to their spawn point, activating upon each defeat of the ender dragon. It is the only way for entities to leave the End dimension without dying.

Generation
The End podium always generates at the coordinates 0,0 in the End, and is de-activated whenever an ender dragon fight is in progress. The y-level of the End podium is determined by the height of the terrain, placing the End portal blocks at the y-level of the highest block found at 0,0. If the End podium spawns at the height limit, the portal blocks are the highest blocks generated, with the top 3 blocks of the bedrock pillar failing to generate due to the maximum build height having been reached. If there are no blocks at 0,0, the portal generates with the base at Y=0.

Construction
Main article: End Podium/Structure

Activated End podium (top view).

The End podium looks similar to the End portal but differs in its design. Instead of a frame of End portal frame blocks, it has a 7-block wide bowl-shaped frame of bedrock, and a central pillar of bedrock with a torch on each side. A dragon egg generates atop the pillar upon defeating the ender dragon for the first time (and the second time in Bedrock Edition).
There are 16 End stone blocks, one under each outer bedrock block, as well as four torches. If any of the blocks other than the dragon egg are removed, they regenerate when the ender dragon is defeated or respawned, making it the only renewable source of End stone.

Behavior
The podium returns the player to their individual spawn point. The credits roll when a player enters the End podium for the first time. If the player doesn't have a spawn point or it is obstructed, they return to the world spawn. If the player's respawn point is set with a respawn anchor, the charge will not be used upon returning.
If an entity other than a player goes through, like a falling block or a thrown item, it is sent to the world spawn. The area it arrives in remains loaded for 15 seconds,‌[JE  only] similar to the behavior of Nether portals.

Issues

Trivia
In Bedrock Edition, if the player manages to break all of the End portal blocks in the End podium, the entire structure regenerates after 5 seconds. If all of the portal blocks have End crystals above (so the fire constantly eliminates the portal), this regeneration process repeats until a portal block successfully regenerates.
If the End podium generates at the tallest possible height and the ender dragon is defeated, the portal blocks generate in the End podium as normal, but the dragon egg does not spawn due to its intended location surpassing the build height limit.
In Bedrock Edition, if there are other End portal blocks in the End and the End podium structure is completely destroyed, it does not regenerate until the other end portal blocks are removed.
