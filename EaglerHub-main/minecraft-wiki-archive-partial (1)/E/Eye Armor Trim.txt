An eye armor trim is a type of smithing template used in smithing tables to add a trim to armor. It is consumed when used, but can be duplicated using an existing template, end stone, and seven diamonds.

Smithing ingredient

Using the smithing table, the eye armor trim can be applied to any armor piece, using any trim material.
