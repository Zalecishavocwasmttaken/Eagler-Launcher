This article is about the command in Java Edition Classic.   For the current command to set a player's spawn, see Commands/spawnpoint.   For the current command to set the world spawnpoint, see Commands/setworldspawn.



This page describes content that has been removed from Java Edition. 
This feature was present in earlier versions of Java Edition, but has since been removed. This feature has never been present in other editions of the game.

Sets the current location as the default spawn location for new players.
This is the Java Edition Classic equivalent of /setworldspawn.

Syntax
setspawn
