This feature is exclusive to Minecraft Education. 

Code builder
The code builder is a code designing UI that can be accessed via pressing the C key on computer devices or the third icon resembling the agent at the top-middle area on mobile devices.

Usage
See also: Minecraft MakeCode

The code builder is used to program the agent and other in-game events using Microsoft MakeCode.
