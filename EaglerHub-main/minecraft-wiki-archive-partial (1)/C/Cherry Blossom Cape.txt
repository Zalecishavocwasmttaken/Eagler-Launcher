The Cherry Blossom cape‌[JE  only] or Cherry Cape‌[BE  only] is a cape given to players who voted on the 2023 Mob Vote or joined the 2023 Mob Vote Event server.

Appearance
The cape design resembles the pink leaves of cherry trees.
The elytra features a four-tone gradient pattern from white from the bottom to pink to the top.

Distribution
Java Edition
In Java Edition, this cape was given to players who voted on the 2023 Mob Vote through minecraft.net, the Minecraft Launcher, or the 2023 Mob Vote Event server.
Joining the server but not voting did not grant the cape to the player in Java Edition.

Bedrock Edition
In Bedrock Edition, this cape was given to players who joined the 2023 Mob Vote Event server.
Voting but not joining the server did not grant the cape to the player in Bedrock Edition.

History
October 10, 2023
The Minecraft Launcher is updated to include a Minecraft Live 2023 section. In this section, a QNA states that players will be able to "nab a unique cape just for swooping into the live event map".October 12, 2023
The cape is added to Bedrock Edition. Due to a bug, it can be seen in Bedrock Edition 1.16.0.October 13, 2023
The server opens, making the cape available in Bedrock Edition.

The cape isn't transferred to Java Edition accounts, and it has not been announced to be planned.October 26, 2023
The cape starts to be rolled out in Java Edition to players who voted on the 2023 Mob Vote. No announcements are made by Mojang.October 30, 2023
The Java Edition API name has been changed from "Cherry Blossom Cape" to "Cherry Blossom".
