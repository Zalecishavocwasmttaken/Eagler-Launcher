Allows adding or removing post effects to players.

Syntax
/posteffect add <players> <posteffect>
Adds the post effect to the players, if it doesn't already exist.
/posteffect clear <players>
Removes all post effects from the players, if any exist.
/posteffect list <target>
Lists all post effects applied to the player, if any exist.
/posteffect remove <players> <posteffect>
Removes the post effect from the players, if it exists.
Arguments
<players>: entity

Specifies one or more players to modify.
Must be a player name, a target selector or a UUID.  And the target selector must be of player type.
<target>: entity

Specifies a player to show the post effects applied list.
Must be a player name, a target selector or a UUID.  And the target selector must be of single-player type.
<posteffect>: resource_location

Specifies the post effect to be added/removed. To be effective, the post-processing effect must be in assets/<namespace>/post_effect. In vanilla, the post effects are minecraft:blur, minecraft:creeper, minecraft:entity_outline, minecraft:invert, and minecraft:spider. See post effect.
Must be a resource location for an unregistered content.
