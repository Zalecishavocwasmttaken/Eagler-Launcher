This page describes content that has been removed and was only present in earlier versions of Minecraft. 
It is still possible to create cat variant tags via datapack, this page simply lists tags that are not longuer present in the game.

Cat variant tag was a group of cat variants.
The cat variant tags are under data/<namespace>/tags/cat_variant folder of data pack.
