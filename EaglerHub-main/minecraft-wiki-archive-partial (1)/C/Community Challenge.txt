Community Challenges are global events that are created to promote the release of a game drop by releasing character creator items and other rewards after a global challenge is completed by players, typically using features added in the associated game drop.

Java Skins
Community challenges often release skins for Java Edition because the Character Creator items are exclusive to Bedrock Edition. Some of these skins are simplified versions of certain character creator items, which are made to meet the limitations of skins in Java Edition.
