Controls the swinging animation of entities' hands.

Syntax
/swing [<targets>] [mainhand|offhand]​[until: JE 26.3]
/swing [<targets>] [mainhand|offhand] [<animation>] [<duration>]​[upcoming: JE 26.3]
Arguments
<targets>: entity

Specifies entities to swing. Defaults to @s (the command executor).
Not all entities will animate a swing on the client side.
Must be a player name, a target selector or a UUID.
mainhand|offhand

Specifies the arm to swing. Defaults to mainhand.
<animation>: swing_animation​[upcoming: JE 26.3]

Specifies the swing animation to play. Defaults to whack.
Must be whack, stab, or none.
<duration>: time​[upcoming: JE 26.3]

Specifies the duration of the swing animation. Defaults to 6t.
It must be a single-precision floating-point number suffixed with a unit. It must be not less than 1 gameticks. Units include:d: an in-game day, 24000 gameticks;s: a second, 20 gameticks;t (default and omitable): a single gametick; the default unit.The time is set to the closest integer after unit conversion to gametick. For example. .5d is same as 12000 gameticks.
