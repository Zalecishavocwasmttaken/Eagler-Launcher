Syntax
/packstack <stackType: stackType> [verbose: verbose] [exclude-vanilla: exclude-vanilla]
Display resource packs and behavior packs data in the chat bar.
Arguments
stackType: stackType: Type of pack. client is resource packs, server is behavior packs.
verbose: verbose: Show details.
exclude-vanilla: exclude-vanilla: Exclude the vanilla package.
